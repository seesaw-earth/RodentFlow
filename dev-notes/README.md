# Development notes

Notes written while RodentFlow was developed, kept for reference. They describe design decisions, verification and release preparation for each version. Some of them mention files that are not part of this repository (synthetic test videos, release archives).

| File | Contents |
|---|---|
| `DATA_PROCESSING_DESIGN_1.1.md` | Design of the 1.1 data processing: assays, metric definitions, statistics, import formats (Chinese) |
| `BUILD_NOTES.md` | Per-version build notes and the verification done before each release |
| `LOCALIZATION.md` | How the English / Simplified Chinese translation is organized and how to change it |
| `RECOVERY_CHECKPOINT_NOTES.md` | How a full-video analysis is checkpointed and resumed |
| `ENERGY_OPTIMIZATION_NOTES.md` | Decoding and memory choices for long videos |
| `TEST_CHECKLIST.md` | Manual test checklists for a real iPhone |
| `APP_STORE_RELEASE.md` | App Store identity and listing text used for the published app |

The user manual lives in [`../docs`](../docs) and is published at https://seesaw-earth.github.io/RodentFlow/.
