# 追踪原理

追踪把视频的每一帧变成以厘米计的位置。它是唯一慢的一步，只做一次；之后的一切（区域、阈值、指标、统计）在你修改设置时都会瞬间重新计算。

## 姿态追踪的步骤 {#pose}

| 步骤 | 做什么 |
|---|---|
| **1 · 读帧** | 按顺序解码各帧并保留时间戳，转正方向。开启*只识别场地范围*（默认）时，只保留标定的场地及 5 %、12 % 或 25 % 的外扩。 |
| **2 · 找到小鼠** | 画面缩放到 960 × 960 像素交给 Core ML 姿态模型。模型给出候选动物，每个都有框、分数和 6 个带置信度的关键点：鼻尖、左耳、右耳、颈部、身体中心、尾根。单鼠范式保留最好的候选；双鼠范式保留两个并分配身份（见下）。 |
| **3 · 像素到厘米** | 标定把画面映射到场地地面。方形场地做透视校正，相机略有倾斜也能得到真实的厘米。 |
| **4 · 清理** | 置信度低于 0.5 的关键点不用；需要不可能速度（超过 150 cm/s）才能到达的位置被剔除；不超过 0.5 s 的缺口用直线插值补上；轨迹在 0.15 s 内平滑。居住者–入侵者用更轻的设置（平滑 0.07 s、缺口 0.2 s），保留 100–200 ms 的扑咬。 |
| **5 · 派生** | 身体中心的速度；从双耳中点到鼻尖的头朝向；从颈部到尾根的身体轴；头–身夹角；鼻尖到尾根的体长；以及用于冻结判定的运动指数（0.5 s 内的位移，对鼻尖、双耳、身体中心和尾根取平均）。 |
| **6 · 标记** | 落在标定场地之外的点会在回看和逐帧数据中标出，并给出离场地的距离。只标记，不修改。 |

这些设置都随每次实验列出，并写进方法学文字。[模型](../models.md)页面介绍四个模型，[速度与精度](./performance.md)说明它们有多快、多准。

## 两只鼠，两个身份 {#identity}

两只鼠时，逐帧与前一帧匹配的方法一旦动物接触就会出错。RodentFlow 改为先读完**整段录像**再分配身份：

1. 找出两只动物明显分开、身份确定的片段。
2. 借助运动和身体轴，把这些片段跨过近距离接触连接起来。
3. 从这段视频中学习两只动物在毛色亮度、标记或体长上是否有稳定差异，并用这个差异确定连接。
4. 仍不确定的连接会标出供复核（*疑似交换*、需核对的时刻）。**从这里交换 A / B** 一下就能纠正交换，并重新计算结果。

一黑一白时，MousePose6DyadBW 会找到两只鼠，较亮的就是白鼠。居住者–入侵者实验中，入侵者进入之前的那段用来识别居住者和进入时刻。

## 质心法 {#centroid}

质心法是 RodentFlow 1.x 的追踪方法。它从整段视频中分散取帧，建立**空场地**图像，从每一帧中减去它，跟踪差异最大的区域的中心：即身体质心，每秒 10 个样本。小鼠在一处停留很久会融进背景；追踪器会检测并修复这种“残影”。它不需要模型，只要地面与毛色有对比就能用，给出区域、路径和时间类指标。完整说明见[旧版本](../archive/principles/tracking.md)。

## 多格悬尾 {#tst}

悬尾实验关心的不是小鼠在哪里，而是它动不动。格子自动找到；每只小鼠有一个覆盖其全部活动范围的固定**运动框**，先对齐画面抵消被动摆动，运动量是小鼠像素中逐帧变化的比例。运动量低于阈值（默认 2 %）并持续至少 1 秒即为不动。见[多格悬尾](../tasks/tail-suspension.md)。

## 每台设备数值相同 {#same}

iPhone、iPad 和 Mac 编译同一套分析代码，所以同一段视频、同样的标定和设置给出同样的数值。Mac 导入手机上的分析时会重新计算，并显示两者是否一致。
