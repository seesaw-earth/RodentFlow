# 从位置到指标

追踪每 0.1 s 产生一个样本，包括：时间、以场地厘米表示的位置、是否检测到动物、迷宫中的区域，以及运动指数。所有视频指标都按本页的规则由这些样本计算。这些规则在追踪之后才应用。在结果页修改区域或阈值后，App 用已保存的样本在一瞬间重算全部指标，不需要视频。

## 时间

每个样本代表**到下一个样本之前的时间**，通常是 0.1 s。如果视频中间有缺口（比如丢了一段），一个样本最多只代表五个采样间隔（0.5 s），这样缺口不会把时间都算到动物最后出现的区域里。

**分析窗口**把所有计算限制在视频的一部分。*起始于* 从第一个样本算起，*长度* 是计分时长（0 = 到结尾）。潜伏期从窗口开始时计算。

## 区域与区域时间

区域是以场地厘米定义的范围：中央方块、一条臂、一个箱室、物体周围的区域、一个象限。区域时间是位置落在该区域内的**检测到动物**的样本所代表的时间之和。

**百分比以检测到动物的时间为分母。** 例如，中央区时间 % = 中央区时间 / 检测到动物的时间 × 100。这样，少量未检测到的样本不会让百分比偏向外周。各范式特有的比例定义见[各范式页面](../assays/index.md)：开放臂 % = 开放臂 / （开放臂 + 闭合臂），明箱 % = 明箱 / （明箱 + 暗箱），象限 % = 象限时间 / 检测到的游泳时间。

## 进入与进入标准

位置会有几毫米的抖动。站在区域边界上的动物，如果不做处理，会产生几十次“进入”。因此，动物**在新区域里停留满进入标准**后才计为一次进入，进入时刻记为它越过边界的那一刻。

| 实验范式 | 进入标准（默认） |
|---|---|
| 旷场、新物体识别 | 0.3 s |
| 十字迷宫、Y 迷宫、T 迷宫 | 0.25 s |
| 明暗箱、位置偏好 | 0.5 s |
| Barnes 迷宫 | 0.2 s |

未检测到动物的样本不会中断停留：在别处看到动物之前，默认它还在原来的区域。分析开始时动物所在的区域不算一次进入。如果动物一开始就在某区域内，到该区域的潜伏期为 0；如果始终没有进入，潜伏期为窗口长度。

这和人工打分要求“四爪都进入臂内”是同一个道理。只是追踪器看到的是身体中心而不是爪子，所以用时间来表达。

## 距离与速度

**距离**是**相邻两个检测到的样本**之间直线步长的总和。进入或离开未检测时段的那一步不计入，所以动物藏起来一段时间后再出现，位置的跳变不会被当成奔跑。

某个样本的**速度**是它前后两个相邻样本之间的距离除以它们的时间差，10 Hz 下为 0.2 s（中心差分）。只有三个样本都检测到时才有定义。在 0.2 s 上取平均，毫米级的抖动就不会被当成运动。

**平均速度** = 总距离 / 窗口时长。水迷宫为游泳路径 / 游泳时间。

## 运动与不动

速度达到或超过运动阈值（旷场默认 2 cm/s）的样本计为**运动**。**运动时间 %** = 运动时间 / 速度可计算的时间。**不动时间**把低于阈值、且持续至少最短时长（2 s）的片段相加，更短的停顿不计。

旷场中的不动时间衡量的是缓慢移动。恐惧条件化的**僵直**更严格，使用运动指数（见下文），因为蜷缩的动物身体可能有轻微移动，而身体中心并没有动。

## 迷宫几何 {#maze-geometry}

迷宫用中线校准，而不是用矩形。每条臂从交汇点（J 或 C）延伸到末端手柄，并具有所填的长度和宽度。

<figure>

![迷宫投影](/img/maze-projection.zh.png)

<figcaption>追踪到的位置被分配给中线最近（以臂宽为单位衡量）的那条臂，然后表示为沿该臂的距离加横向偏移，每条臂用自己的像素/厘米比例换算。靠近交汇点时，位置属于中央区。</figcaption>
</figure>

- **中央区**：Y 迷宫和 T 迷宫中，沿臂方向距交汇点 1.1 个臂宽以内的位置。十字迷宫中，是两臂交叉处的方块（边长 = 臂宽），可以用 *中央区外扩* 扩大。
- **搜索范围**：追踪器只在臂的通道内寻找动物，通道略宽于所填臂宽，所以迷宫外的动静（比如实验人员的手）会被忽略。
- **进臂**使用迷宫的进入标准（0.25 s）。经过中央区回到同一条臂，算作再次进入。

## 圆形场地

**水迷宫**

- *象限*：以平台相对池心的方向为中心的 90° 扇区为目标象限，此外还有相对的对侧象限和两个相邻象限。
- *逃避*：动物第一次进入平台区、并在其中停留满所需时间（1 s）的时刻。游泳相关的指标只统计到逃避为止。
- *到平台的平均距离*（Gallagher proximity）：游泳过程中到平台中心距离的平均值。与潜伏期不同，它反映动物在整个游泳过程中离平台有多近。
- *穿越次数*：每次进入平台区都计数，没有最短停留要求。
- *贴壁区时间*：在距池壁贴壁区宽度以内的环带中的时间。

**Barnes 迷宫**

- *洞*：沿经过目标洞的圆环均匀分布。
- 一个位置归属于洞区半径内**最近**的那个洞，所以相邻洞区不会重复计数。
- *访问*使用进入标准（0.2 s），*错误*是对非目标洞的访问。
- *逃避*：动物最后一次出现时距目标洞在两个洞区半径以内，之后至少 3 s 看不到，即判定为进入了逃生箱。

## 僵直 {#freezing}

僵直由**运动指数**测量：对每个样本，统计场地内与 0.1 s 前的上一个样本相比灰度变化 **≥ 20 级**（满量程 255）的像素比例。20 级高于视频压缩在完全静止动物边缘造成的 12–24 级闪烁，又远低于对比明显的动物真正运动时引起的变化。

为了让指数与动物大小和相机距离无关，再除以动物的**典型身体面积**，即整个实验中追踪到的身体大小的中位数：

> 运动（占身体面积 %）= 变化像素数 / 身体面积中位数 × 100

低于僵直阈值（5 %）的样本为**静止**。连续静止持续至少最短僵直时长（1 s）即为**僵直**。全程、基线、CS 期和试次间隔的僵直，分别是各时段内僵直时间所占的比例，时间从你设定的实验程序起点开始计算。

## 质量控制

每条视频结果都带有 **追踪成功样本 %**，低于 90 % 时 App 会给出提示。明暗箱、恐惧条件化和 Barnes 迷宫除外，因为这些范式中动物本来就会藏起来。各范式还有专门的提示：标记缺失、进臂太少、探索不足、未到达平台或目标、摄入量为负等。提示显示在结果顶部，也会在组间分析的统计备注中说明，但结果绝不会被自动排除。
