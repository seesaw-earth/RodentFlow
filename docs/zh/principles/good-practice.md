# 让结果经得起检验

::: info

**RodentFlow 是科研辅助工具，不是诊断工具。**它的指标是基于关键点几何关系或运动信号的算法估计，质量取决于你的录像、标定和阈值；桌面版分析器是原版算法的移植，与原版 App 的数值一致性仍在验证中。

:::

1.  **在自己的装置上验证。**每个范式人工评分几段视频（对分组设盲），与 RodentFlow 结果对比，在正式实验之前把阈值调好一次。[BORIS](https://www.boris.unito.it/) 是免费的人工行为评分工具。
2.  **固定参数。**同一研究中所有动物使用相同的标定方法、分析时间段和阈值。这些参数都会写入每份导出。
3.  **每次实验都复核追踪**（检查 100 帧不到一分钟），并提前确定排除标准（如掉落迷宫、检出率 \< 80%）。App 会列出质控警告，但从不自动排除。
4.  **尊重实验单位。**n = 小鼠数，而不是实验数或帧数（[Lazic 等 2018](https://doi.org/10.1371/journal.pbio.2005282)）。不要合并不同阶段。
5.  **App 内统计仅作初步参考**，请对导出的 `animals.csv` 运行你预先注册的分析。
6.  **如实报告：**App 版本、范式、模型或追踪方法、标定、分析时间段、阈值、排除情况——`README_methods.txt` 和移动版的“方法说明”可作为初稿。请参照 [ARRIVE 2.0 指南](https://arriveguidelines.org/)。
7.  **谨慎解读。**“鼻尖靠近物体”是探索的近似指标；“运动量低”是僵直或不动的近似指标。焦虑、记忆、应对类指标都应配合运动能力对照一起解读。
