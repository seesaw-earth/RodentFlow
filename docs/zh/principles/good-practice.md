# 让结果经得起检验

RodentFlow 按明确的规则从关键点或运动量测量行为。每只动物、每个实验室用的规则都相同，这正是自动评分可重复的原因。下面这些习惯让结果更可靠。

1. **研究开始前与人工评分对照一次**。在自己的装置里，对每个测试人工评分几段视频（对分组设盲），与 RodentFlow 的结果比较。需要时调整一次阈值，然后保持不变。[BORIS](https://www.boris.unito.it/) 是免费的人工评分工具；RodentFlow 回看中的手动标记也会直接给出精确率、召回率和 F1。悬尾实验可以用“用人工评分校准阈值…”自动找到阈值。
2. **固定设置**。同一研究的每只动物使用相同的标定方式、分析时段、模型和阈值。它们随每次实验保存，并写进导出文件。
3. **逐次复核**。把回看过一遍，看看被标出的时刻，并事先确定排除标准（例如从迷宫上掉落、离开场地）。被排除的实验在导出中保留原因。
4. **按动物计数，而不是按实验次数**。n 是动物数（[Lazic 等 2018](https://doi.org/10.1371/journal.pbio.2005282)）。RodentFlow 先在动物内取平均，除非你要求，不会合并不同阶段。
5. **报告你做了什么**。App 版本、范式、模型或追踪方法、标定、分析时段、阈值和排除情况。每次实验的方法学文字和组间导出的 `methods.txt` 可以作为起草的基础。请遵循 [ARRIVE 2.0 指南](https://arriveguidelines.org/)。
6. **按指标的本来含义解读。**“鼻尖靠近物体并朝向它”代表探索；“运动量低”代表冻结或静止；悬尾的不动是一种应对策略。焦虑、记忆和应对类指标请配合运动对照一起解读，例如旷场路程。
7. **保留原始数据**。把原始视频和逐帧导出与结果一起保存，以后任何指标都可以重新计算或核对。

RodentFlow 是用于实验动物研究的科研工具，不是医疗或兽医器械。
