# 统计方法

组间分析根据三件事选择检验：**实验设计**（一个数据点是什么）、**组数**，以及**参数还是非参数**。本页列出所有组合，并解释为什么这样选。

## 分析单位是动物

每只动物在设计的每个水平上只贡献**一个值**。如果一只动物有多条结果，比如同一天内的多个试次、重复测试或合并在一起的多个阶段，这些结果会先**在该动物内平均**，App 会在备注中说明。所有检验和图表中的 n 都是动物数。

把试次当作相互独立的动物来检验（伪重复），会让 p 值小得多。先在动物内平均就能避免这一点。对于学习曲线，*跨天比较* 把天作为重复因素保留下来，而不是简单丢弃。

## 用哪种检验

### 组间比较、阶段间变化

*阶段间变化* 先计算每只动物的差值（到 − 从），之后与 *组间比较* 完全相同。

| 组数 | 参数检验 | 非参数检验 |
|---|---|---|
| 2 | **Welch t 检验**（双尾），均值差及 95 % CI，**Hedges' g** | **Mann–Whitney U 检验**（无并列且每组 n ≤ 20 时用精确 p 值，否则用带并列和连续性校正的正态近似），**秩二列相关 r** |
| ≥ 3，两两比较 | **单因素方差分析**（η²）+ **Tukey–Kramer HSD** | **Kruskal–Wallis 检验**（η²<sub>H</sub>）+ **Dunn 检验**，Holm 校正 |
| ≥ 3，与第一组比较 | 单因素方差分析 + 各组与第一组的 **Welch t 检验**，Holm 校正 | Kruskal–Wallis + 各组与第一组的 Dunn 检验，Holm 校正 |
| 各组与机会水平比较（可选） | **单样本 t 检验**（Cohen's d） | **Wilcoxon 符号秩检验**（无并列且 n ≤ 30 时为精确法），配对秩二列相关 r |

### 跨天比较、时间进程

动物为行，水平（天、时间段、CS、试次）为列。

| 组数 | 参数检验 | 非参数检验 |
|---|---|---|
| 1 | **单因素重复测量方差分析**，Greenhouse–Geisser 校正 | **Friedman 检验**（Kendall's W） |
| ≥ 2 | **两因素混合方差分析**：组别（组间）× 水平（组内，Greenhouse–Geisser 校正），偏 η² | 每个水平分别做 Mann–Whitney 检验，Holm 校正（无总体检验） |
| 事后比较（≥ 2 组） | 每个水平上的组间差异：Welch t 检验，对所有比较做 Holm 校正 | Mann–Whitney，Holm 校正 |

混合方差分析需要完整数据。缺少某个水平的动物不进入方差分析，App 会说明，但仍画在图中。

### 配对测量

| | 参数检验 | 非参数检验 |
|---|---|---|
| 组内 | **配对 t 检验**（Cohen's d<sub>z</sub>） | **Wilcoxon 符号秩检验** |
| 组间 | 组别 × 测量的混合方差分析，其中**交互作用**检验组内差值在各组间是否不同 | 对组内差值做 Mann–Whitney（2 组）或 Kruskal–Wallis（≥ 3 组） |

### 两个因素 {#two-way}

有第二个因素（性别，或把组名拆成两个因素，如基因型 × 处理）时，App 做 **Type III 平方和的双因素方差分析**，各组人数不等时仍然正确。它给出两个主效应和交互作用（偏 η²）、用完整模型合并误差的**简单效应**，以及在每组比较内做 Holm 校正的两两比较，均附 95 % CI。

### 协变量 {#ancova}

**ANCOVA** 用同一动物的另一项指标校正组间比较，例如新奇抑制摄食的家笼摄食量或水迷宫的游速。它给出校正后的组效应、协变量斜率、校正均值 ± SE 及 95 % CI，以及 Holm 校正的两两差异。同时检查各组斜率是否相同（组 × 协变量），并在协变量本身组间不同时提醒。

### 有截止时间的潜伏期 {#survival}

对于部分动物在截止前没有发生事件的潜伏期（水迷宫逃避、被动回避、跳台、视觉悬崖、新奇抑制摄食、攻击潜伏期），页面会另给 **Kaplan–Meier 曲线**（删失动物标 +），以及各组发生数、中位潜伏期和 **log-rank 检验**（χ²，df = 组数 − 1）。柱图和 t 检验把删失的潜伏期按截止时间计入，所以有删失数据时应报告 log-rank 检验。每只动物只能有一条记录；请先筛选到一个阶段、一天或一次。

### 是 / 否指标 {#proportions}

每只动物为 0 或 100 的指标（是否跳下、是否进入暗室、首次是否选深侧、是否攻击）还会作为比例，用 **Fisher 精确检验**（双侧）或**卡方独立性检验**比较。

## 前提检查 {#assumptions}

每次比较都显示每组和模型残差的 **Shapiro–Wilk** 检验，以及方差齐性的 **Brown–Forsythe** 检验。它们只是建议：App 会提示参数或非参数检验哪个更合适，但不会自行更换检验。每组少于 8 只时会提示这些检查的功效很低。

## 效应量 {#effect-sizes}

每个检验都附效应量及其 95 % CI：两组为 Hedges g 和均值差（Welch CI）；Mann–Whitney 为 r = Z/√N、秩二列相关和 Hodges–Lehmann 位移；多组为 η²、ω² 以及每对均值之差（Tukey 同时区间或未校正区间）；配对数据为均值差和 d<sub>z</sub>；双因素方差分析和 ANCOVA 为偏 η²。

## 为什么这样选

- **用 Welch 而不是 Student t 检验。** Welch 检验不假设方差相等。方差相等时它几乎没有损失；方差不等时，它能把假阳性率控制在应有的水平。对于小样本的动物分组，这是合理的默认选择。
- **两两比较用 Tukey–Kramer。** 它控制所有两两比较的族错误率，并能处理各组样本量不等的情况。没有单步方法的场合，即与对照比较和 Dunn 检验，使用 **Holm** 校正，它总是比 Bonferroni 更有检验效能。
- **Greenhouse–Geisser。** 跨天的重复测量很少满足方差和协方差相等（球形性）。校正按 ε 缩小自由度（ε 会一并报告），使 p 值保持有效。
- **每个检验都给出效应量。** 每组 n = 6–12 时，仅凭 p 值很难看出效应有多大。
- **一律双尾检验。** 单尾检验必须在看到数据之前决定，所以不提供切换开关。

## 怎样读统计卡片

两组比较的例子：

> *双尾 Welch t 检验（方差不齐）。*
> t(13.4) = 2.71，p = 0.017，Hedges' g = 1.31
> 均值差（WT − KO）= 4.8，95 % CI [1.0, 8.6]。

卡片接着列出两两比较的校正 p 值和星号（* < 0.05，** < 0.01，*** < 0.001，**** < 0.0001），以及各组的描述统计：n、均值 ± SEM、SD、中位数和四分位数。小于 0.0001 的 p 值显示为“p < 0.0001”。

如果某组动物少于两只，或组内所有数值完全相同，就无法计算检验。卡片会说明原因，而不是给出误导性的结果。
