# Windows 快速上手（10 步）

1.  **安装并打开 RodentFlow**：从 [Microsoft Store](https://apps.microsoft.com/detail/9n4hx4cvmzf8) 安装。在窗口里的语言菜单中切换 English 和中文。
2.  **新建任务**：点 **新建任务…**，起一个名字（如“旷场 第一批”），选择实验范式，点 **创建**。一个任务就是一批动物的一项行为测试。
3.  **添加视频**：选中任务后，点实验列表上方的 **添加视频…**，选择文件。每个视频填写**小鼠编号**、**实验日期**和**实验次数**（必填）；分组和性别可选。**新小鼠的统一分组**和**全部使用第一行的日期**可以一次填满一整列。RodentFlow 能从文件名读出日期时会自动填上；取自文件创建日期的日期会标出来，请核对。点 **添加**。
4.  **打开一次实验**：在列表中点选。每次实验顶部有四步：**实验信息 → 标定 → 结果 → 复核**。
5.  **标定**：把手柄拖到场地和该范式的标记上（杯子、物体、迷宫臂、平台……）。区域按分析实际计数的方式画出来。填写场地的实际尺寸（厘米），检查**范式参数**和**分析时间段**，在**识别**里选择*毛色*。如果几段视频之间摄像头没有动过，点 **把此设置用于本任务全部实验…**。
6.  **分析**：点 **分析**。窗口里显示进度、剩余时间和实时画面；**停止**会暂停，下次点 **分析** 从停下的地方继续。要把所有已标定的实验依次分析，点实验列表上方的 **分析全部可分析的**。
7.  **看结果**：**结果**一步显示该范式的指标、图和一段 Methods 文字。之后改了区域、阈值或分析时间段，点 **更新结果**：用已保存的追踪数据重新计算，不需要重新追踪视频。
8.  **核对追踪**：在**复核**里播放画有骨架的视频（空格播放 / 暂停，← 和 → 逐帧），逐个查看时间轴上的时刻。双鼠实验可以用 **从此帧起交换 A / B** 纠正身份互换。最后把**追踪核对**设为*已核对：追踪正确*或*已核对：追踪有问题*。
9.  **组间比较**：在侧栏点任务，打开任务页，里面是该任务全部实验的**组间比较**。选择设计和指标；RodentFlow 画出每只小鼠，并显示所用的检验和结果，见[组间比较](../guide/groups.md)。
10. **导出**：每张图都有菜单，可存为 PNG（300 或 600 dpi）、矢量 PDF、SVG 或 CSV；组间比较还可以保存统计表和每只小鼠一行的数据（CSV，用于 Prism 或 R）。**打开结果文件夹** 在文件资源管理器中显示该实验的文件；**生成复核视频** 输出画有关键点的视频。

::: tip
一批动物的第一只要仔细标定和核对，再把它的设置复制给其他实验。每次实验用到的设置都和它一起保存，结果随时可以追溯到这些设置。
:::

::: info 显卡还是处理器
在 **识别 › 模型运行在** 中，*自动* 会在每个模型第一次运行时分别测一次显卡和处理器，用更快的那个。如果显卡驱动有问题，选 *处理器（CPU）*。
:::
