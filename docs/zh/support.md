## 报告问题或提问 {#help}

请在 GitHub 上提交 issue：**[github.com/seesaw-earth/RodentFlow/issues](https://github.com/seesaw-earth/RodentFlow/issues)**

Mac 版以前的问题报告在 [RodentStudio-Support 的 issue 列表](https://github.com/seesaw-earth/RodentStudio-Support/issues)里，可以先查一下问题是否已知。

为了更快解决问题，请尽量提供：

1. **App 和版本**：iPhone 或 iPad 在设置 › 通用 › iPhone 储存空间 › RodentFlow 中查看；Mac 在菜单 **RodentFlow › 关于 RodentFlow** 或 TestFlight 中查看。
2. **设备和系统**：iPhone 或 iPad 型号及 iOS 版本；或 macOS 版本，以及 Mac 是 Apple 芯片还是 Intel。
3. **流程和实验范式**：质心追踪、RodentPose、RodentLimb 还是多格悬尾；数据来自视频、手动录入还是导入。
4. **你做了什么，预期是什么，实际发生了什么**，以及错误提示原文。
5. 如果是追踪问题：**预览截图**，方便的话再附一小段视频或模拟测试视频。
6. 如果是导入问题：**文件的前几行**，必要时替换真实的动物编号。

::: warning 注意分享的内容
GitHub issue 是公开的。不要上传未发表的数据、可识别身份的信息，或你无权分享的视频。一张截图或几行匿名数据通常就够了。
:::

## 涉及隐私或保密数据怎么办？

如果问题包含隐私、机构限制或未发表数据，请只创建一个请求私下联系的 issue，不要在公开页面粘贴任何敏感细节。开发者会再安排非公开的沟通方式。

## 支持范围

包括安装和 App 行为、访问你选择的视频文件、Core ML 模型加载、导入导出问题，以及可复现的软件缺陷。RodentFlow 不提供临床、兽医诊断或实验方案方面的建议。

## 源代码

源代码是公开的，见[源代码](./source.md)。欢迎提交 pull request，见 [CONTRIBUTING.md](https://github.com/seesaw-earth/RodentFlow/blob/main/CONTRIBUTING.md)。

## 功能建议

欢迎通过 GitHub issue 提出新的实验范式、指标或导出格式。请描述实验方案、需要的指标，以及它在你的领域里是怎么定义的。附上一篇方法学文献会很有帮助。

发现手册有错？每一页底部都有“在 GitHub 上编辑此页”的链接，也可以[提交 issue](https://github.com/seesaw-earth/RodentFlow/issues/new/choose)。

## 关于
