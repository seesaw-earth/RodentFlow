# iPhone 与 iPad：姿态追踪

::: info
本页根据 Mac 版 RodentFlow 0.7.1 和 iPhone、iPad 版 RodentFlow 1.0（姿态版，原名 RodentStudio）编写。
:::

RodentFlow Mobile 在设备上运行同一个 6 关键点 RodentPose 模型和 16 个 RodentPose 范式。App 有三个标签页：**首页**、**范式库**、**数据**；设置在首页右上角的齿轮图标里。

## 第一次分析

1.  **首页 → 新建分析。**选择范式（或点“常用范式”中的一个；“范式库”介绍了每个范式用到的关键点、输出指标、拍摄与标定要求和参考文献）。
2.  **导入视频：**“从相册选择视频”或“从‘文件’选择视频”。视频会复制一份到本次分析的文件夹，便于之后回看。模型还在加载时，也可以先导入视频并完成标定。
3.  **信息：**填写*编号*（用于文件名和汇总表，建议在识别前填写）、组别（用过的组别会显示在输入框下方，轻点即可填入）、性别、*阶段 / 条件*（轻点 + 添加自己的标签，如“Day 1”“Baseline”；长按可移除）、天、试次和备注。
4.  **识别设置**（也在“信息”页）：*抽帧*（每帧，或长视频每 2 / 3 / 5 帧识别一次——速度和僵直按实际时间计算，但 VTE、探头等快速动作请逐帧）、*先转灰度再识别*（建议开启）、*双鼠模式*（双鼠社交互动）以及*识别范围*。之后修改这些需要重新识别。
5.  **标定：**拖动手柄（标签与 Mac 版相同，见[标定](/zh/mac/workflow#mac-calibrate)）。拖动时对侧上角会出现放大镜。识别完成后打开*叠加已识别轨迹*，可检查标定范围是否与动物的实际活动范围吻合。VoiceOver 用户可在操作菜单中逐步微调手柄。
6.  **识别：**点“开始识别”。识别期间请保持 App 在前台（屏幕不会自动锁定）。切到后台会自动暂停并保存进度，回来后点“继续识别”即可。
7.  **结果：**主要指标（有意义时附刻度，如 0 = 无偏好）、全部指标、图表、识别质量，以及可一键复制的*方法说明（可用于论文 Methods）*。每张图都有 ••• 菜单：*复制图像*、*分享图像…*、*复制数据（CSV，英文）*。
8.  **下一只（同范式）**会用同一范式开始下一次分析；相机没动过时可沿用标定。

## 回看视频

打开“回看视频”可查看姿态叠加、行为区域和 2 秒运动拖尾（仅为显示做了平滑，不影响指标）。用“上一个事件 / 下一个事件”在已判定的行为之间跳转（行为图例同时也是筛选器），可逐帧前后、后退 / 前进 5 秒，速度 0.25×–2×。

## 导出

| 导出项             | 内容                                                                                      |
|--------------------|-------------------------------------------------------------------------------------------|
| 指标汇总 CSV       | 本次分析的全部指标，一行一个                                                              |
| 逐帧分析 CSV       | 平滑后坐标（cm）、速度、头朝向、区域与行为标记                                            |
| 原始关键点 CSV     | 模型输出的像素坐标与置信度                                                                |
| 完整报告 JSON      | 指标、参数、标定、质量与方法说明                                                          |
| 汇总表（“数据”页） | “导出汇总表”可导出全部或当前筛选的分析——每次分析一行，用于在 R、Python 等工具中做组间分析 |

导出通过系统共享面板完成（存储到“文件”、隔空投送到 Mac、邮件……）。CSV 为带 BOM 的 UTF-8，Excel 可直接正确显示中文；列名始终为英文。

## 管理存储空间

- 在**数据**页左滑或长按某次分析，可“删除视频副本”（保留姿态数据和结果，但无法再回看视频或重新识别）或“删除此分析”（全部永久删除）。
- 每次分析的文件夹位于“文件”App › 我的 iPhone/iPad › RodentFlow › Sessions：`session.json`（设置与指标）、`pose.mpt`（逐帧关键点）、`video.*`（视频副本）。参见 [Apple：iPhone 上的“文件”](https://support.apple.com/zh-cn/guide/iphone/iphc61044c11/ios)。
- 把导出文件传到 Mac：可用隔空投送、“文件”App 或 [访达文件共享](https://support.apple.com/zh-cn/119585)。Mac 版与移动版目前各自保存独立的数据库：如需把一项研究汇总到一起，请在 Mac 上分析原始视频，或合并导出的 CSV。
