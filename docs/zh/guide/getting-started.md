# 快速上手

下面以一段旷场视频为例。其他范式的步骤完全相同，只是要放的手柄和得到的指标不同。

## iPhone 或 iPad {#phone}

1. **打开范式库**，选**旷场**（或在首页点**新建分析**，从列表中选）。范式库按领域分组：社交、导航、焦虑、记忆、运动、通用，最后是质心法和多格悬尾。每个测试都有一页说明它测什么。
2. **选择视频**（来自相册或“文件”），再选小鼠的**毛色**：*深色*（默认）或*白色*。
3. **填写动物信息**：动物编号、组别、性别，测试有阶段、天、次时也一并填写。之后“组间”页靠这些字段分组。
4. **标定**：在第一帧上把四个角的手柄拖到场地内侧的四个角，输入宽和高（厘米）。其他范式还有各自的手柄（杯子、物体、迷宫臂、平台、庇护所），每个手柄都有标注。
5. **识别**：点**开始识别**。只分析场地范围（外加一点边距）。识别时可以继续用手机，进度会保存，暂停后从停下的地方继续。
6. **回看**：播放视频，小鼠身上画出 6 个关键点。下面的时间轴显示每种评分行为；需要检查的时刻（例如“超出标定范围”）会被标出。
7. **结果**：路程、中央区时间、进入次数、静止等指标，每个都附定义；另有轨迹图、热图和时间进程。点**导出数据**得到表格和图。

每只动物重复一遍。做完几只后打开**组间**，选范式和指标，查看比较结果：见[组间比较](./groups.md)。

## Mac {#mac}

1. **新建任务…**，选**旷场**并命名（例如“旷场 – 第 3 批”）。
2. **添加视频**：把视频拖到任务上。每段视频是一只动物的一次实验：填写动物编号、录制日期和实验次数；组别和性别属于动物。
3. **标定**一段视频，再把标定应用到同一机位拍摄的其他视频。
4. **分析**：Mac 依次追踪各段视频，边做边存，长录像暂停或重启后也不会丢失。
5. 逐个**复核与导出**，再对整个任务做**组间比较**。

[Mac 快速上手](../mac/quick-start.md)会一步步介绍 Mac 的操作。

## 正式实验之前 {#before}

- 先在真实装置里录一段短视频并分析；[怎样拍出好追踪的视频](./recording.md)列出了最重要的几点。
- 同一研究的所有动物使用同一套设置。每次分析用到的设置都随结果保存，并写进方法学文字。
- 双鼠范式请使用毛色不同的小鼠，或给其中一只做标记；见[双鼠社交互动](../tasks/dyadic-social.md#setup)。
