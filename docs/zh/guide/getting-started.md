# 快速上手

下面用一段旷场视频走完一次完整分析，再做组间比较。除了完整分析本身需要的时间，大约五分钟。其他实验范式的流程完全一样，区别只在场地和设置。

::: tip 拍摄之前
追踪效果在拍摄时就已经决定了。如果还没开始录像，请先读[怎样拍出好追踪的视频](./recording.md)：相机在正上方，场地尽量占满画面，光照均匀，动物和地面对比明显。
:::

## 1. 选择实验范式和视频

1. 打开 RodentFlow，默认在 **实验** 标签页。
2. 在 **新实验** 卡片里点实验范式那一行，选择 **旷场 / 中央区**。
3. 点 **从照片中选择视频分析**。如果视频在“文件”App、iCloud 云盘或 U 盘里，点 **从“文件”中选择视频**。

App 读取视频信息后进入 **设置** 页面。顶部的步骤条是 *开始 → 设置 → 预览 → 结果*，已经可以到达的步骤都可以点击，前后跳转。

## 2. 填写设置

设置页是一个可滚动的页面，顶部的分区菜单可以跳到各个卡片。

| 卡片 | 本例中填写 |
|---|---|
| **实验信息** | **小鼠编号**（如 `WT01`）、**组别**（如 `WT`）、**性别**。如果视频文件里有拍摄日期，实验日期会自动取自视频。 |
| **实验范式与场地** | 场地形状选 **矩形**；**宽度** 和 **高度** 填场地*底面内侧*的尺寸（cm），如 40 × 40。 |
| **分析设置** | 保持默认。中央区边长为场地边长的 50 %。这里的所有设置以后都能改。 |
| **10 秒预览** | 起点保持不动，或挪到动物在走动的一段。 |
| **校准** | 把手柄 **1 → 2 → 3 → 4** 沿场地一圈，依次拖到底面的四个内角上。 |

点底部栏的 **生成预览 ›**。

## 3. 检查预览

App 追踪 10 秒，并把追踪点叠加在视频上回放。屏幕上的那个问题就是最关键的：**圆点是否始终跟随小鼠？**

- 如果是，并且场地轮廓和底面边界吻合，就继续。
- 如果圆点跳到阴影、反光或墙上，用 **‹ 设置** 返回，修正校准或换一段预览，然后点 **更新预览**。常见原因见[常见问题与排错](../reference/faq.md)。

## 4. 分析完整视频

点 **分析完整视频**。App 从头到尾以每秒 10 个样本读完整段录像，进度条显示已处理的样本数和预计剩余时间。

- **暂停并保存** 会停下来，保留已经分析的部分。切换到其他 App 时会自动暂停并保存。
- 分析过程中大约每 30 秒保存一次检查点。如果 App 被关闭，开始页会出现 **发现未完成的分析 → 继续分析**。

分析完成后，结果自动保存，原始追踪文件写入 *文件 › 我的 iPhone › RodentFlow › Experiments* 下的运行文件夹。

## 5. 查看结果

点 **打开结果**，可以看到：

- 指标卡片：总距离、中央区时间和进入次数、进入中央区潜伏期、不动时间、运动时间；
- 场地图，可在 **轨迹** 和 **热图** 之间切换；
- 分时间段的序列，如每 5 分钟的距离；
- **方法**：说明每个数值的计算方法和所用参数；
- **分析设置**：修改中央区大小、运动阈值等。指标根据已保存的位置立即重算，不会重新追踪视频。

## 6. 分析下一只动物

点 **下一只动物**。实验范式、组别、阶段和天数会保留，接着选下一段视频。如果相机没有动过，在设置页点 **使用上次设置**，沿用场地尺寸、校准和分析设置。确认手柄仍在四个角上，再像前面一样生成预览。

## 7. 组间比较

每组都有几只动物的结果后，打开 **组间分析** 标签页，或在某条结果上点 **在组间分析中比较**。

1. **实验范式**：旷场 / 中央区。
2. **分析**：设计选*组间比较*，测量指标选*总距离*（或其他指标）。
3. **组别**：调整顺序，把对照组放在第一位。点颜色圆点可以换颜色。
4. **图表**：柱状、箱线或均值 ± SEM，每只动物显示为一个点。
5. **统计**：使用了哪种检验、为什么，各组描述统计和两两比较结果。

可以把图导出为 PNG、统计结果导出为 JSON，或者复制一段文字摘要贴到实验记录里。

## 不用视频也能试 {#try-it-without-a-video}

下面这些示例表格是专门用来试用导入功能和组间分析的模拟数据。下载到 iPhone，在新实验卡片中选好对应的实验范式，再点 **导入表格**。

| 文件 | 选择的实验范式 | 演示内容 |
|---|---|---|
| [example_open_field_metrics.csv](/samples/example_open_field_metrics.csv) | 旷场 / 中央区 | 三组 → 方差分析 + Tukey–Kramer |
| [example_open_field_chinese_headers.csv](/samples/example_open_field_chinese_headers.csv) | 旷场 / 中央区 | 同样的数据，列名为中文 |
| [example_nor_test.csv](/samples/example_nor_test.csv) | 新物体识别 | 人工打分的时间 → 辨别指数；其中一只因探索不足被标记 |
| [example_mwm_acquisition.csv](/samples/example_mwm_acquisition.csv) | Morris 水迷宫 | 每天 4 个试次 × 5 天 → 学习曲线和混合方差分析 |
| [example_beam_trials.csv](/samples/example_beam_trials.csv) | 平衡木 | 每天多个试次 |
| [example_sucrose_raw.csv](/samples/example_sucrose_raw.csv) | 糖水偏好 | 每天的瓶重原始数据 → App 计算偏好 |
| [example_bandit_trials.csv](/samples/example_bandit_trials.csv) | 双臂老虎机任务 | 每只小鼠 300 个试次 → 赢-留、输-换和 Q-learning 拟合 |
