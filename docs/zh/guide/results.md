# 结果与导出

## 结果页 {#page}

每次实验有一个结果页，iPhone、iPad 和 Mac 上都一样。

- **指标**。这个范式的每个指标及其数值和定义，与[范式页面](../tasks/)一致。修改区域、阈值或分析时段后，数值无需重新追踪就会更新。
- **图**。轨迹、起点和终点，以及热图（三箱实验另有一张鼻尖热图）。热图可以叠加在原视频画面上，也可以与原图并排。图上的任何组件都可以关掉（杯子、物体、迷宫臂、区域名称、轨迹、图例、比例尺……）；按范式记住，所以每只动物的图看起来都一样，导出时也是如此。
- **时间进程**。主要指标按时间段的数值，随实验保存，组间页可以据此画时间进程。
- **方法学**。一段描述模型、设置和所用定义的文字，可改写后用于论文。
- **备注与复核状态**。备注、复核结论，以及排除时的原因。

## 导出 {#exports}

导出文件的列名始终是英文，不受界面语言影响。在 iPhone 和 iPad 上点**导出数据**并勾选需要的内容；在 Mac 上用实验的“复核与导出”步骤，或一次导出整个任务。

| 导出内容 | 包含什么 |
|---|---|
| **指标** | 每次实验一行，包括所有指标、动物信息、设置和模型。 |
| **逐帧 CSV** | 每帧：关键点（厘米）、速度、头朝向、身体朝向、区域和行为标记（例如 `on_platform`、冻结）、质量标记如 `outside_arena` 和 `outside_arena_dist_cm`，以及 `recording_start`，即视频文件里记录的录制时间，便于和其他设备的数据对齐。 |
| **DeepLabCut 格式关键点** | DeepLabCut 的 CSV 格式（`scorer`、双鼠时的 `individuals`、`bodyparts`、`coords`），可直接交给 Keypoint-MoSeq 等工具。早期格式的原始关键点 CSV 仍可导出。 |
| **行为片段** | 每段行为一行：动物、行为名、开始、结束和时长（视频秒数和帧号）、相对分析起点的时间、阶段、天、次、组别和性别。包括自动判定的行为、复核标记（`category = qc`）、CS 或逼近刺激等刺激时段（`category = epoch`）以及你的手动标记（`source = manual`）。同时附带 BORIS 形式的 START/STOP 事件表、含定义和合计的元数据文件，有手动标记时还有一致性表。 |
| **报告** | 整次实验的 JSON：设置、标定、指标、事件。 |
| **图** | 矢量 PDF 和 300 或 600 dpi 的 PNG（Mac 另有 SVG），可选期刊栏宽 85、114 或 174 mm，或自定义尺寸。 |
| **仅 Mac** | 在视频上画出关键点的标注 MP4，以及质控图片和表格。 |

整组的导出（Prism 表、供 R 和 Python 用的长格式表、统计报告）见[组间比较](./groups.md#export)。
