# 结果页

每次分析的最终产物是一条**结果**：一只动物在一个实验阶段（一个阶段、一天或一个试次）的数据。一条结果包含动物信息、各项指标、时间序列、所用参数、质量提示，视频结果还会链接到追踪数据。组间分析使用的就是这些结果。

## 查找结果

实验标签页的 **结果** 卡片显示已保存结果的数量和最近的几条。**全部结果** 打开完整列表：

- 可按编号、组别或阶段搜索；
- 用右上角的菜单按实验范式筛选；
- 左滑或打开一条结果可以删除它。

结果同时以文件形式保存在 *文件 › 我的 iPhone › RodentFlow › Results* 中，每个实验范式一个文件夹。见[文件与数据](../reference/files.md)。

## 结果页的内容

从上到下依次是：

### 标题与导航

标题是动物编号。**▲ ▼** 跳到同一范式的上一条或下一条结果，便于逐只检查一批动物。共享菜单提供 **共享结果（JSON）**，视频结果还有 **共享追踪文件夹**。

需要注意的地方会以质量提示的形式显示在顶部，例如：

- *只有 72% 的样本检测到小鼠——请检查追踪预览。* 检测到的样本少于 90 % 时出现。明暗箱、恐惧条件化和 Barnes 迷宫中动物本来就会有时看不见，所以不显示这条提示。
- *探索不足：共 6.2 s（标准 10 s）。*（新物体识别）
- *60 s 内未找到平台（潜伏期记为试次最长时间）。*（水迷宫）
- *试次内未访问目标洞。*（Barnes 迷宫）
- *进臂少于 3 次——无法计算交替率。*（Y 迷宫）

提示只是提醒你检查，并不会自动排除。是否排除这只动物由你决定（见下文“详细信息”）。

### 结果

该范式的全部指标及单位。每个指标的定义见[各范式页面](../assays/index.md)。

### 场地（或僵直）

视频结果会在场地上画出追踪轨迹和各区域。**图形** 可在 **轨迹** 和 **热图** 之间切换，热图显示在每个位置停留的时间。

有标记的范式会把标记显示为可拖动的点：

| 标记 | 实验范式 | 含义 |
|---|---|---|
| **A**、**B** | 新物体识别 | 物体中心 |
| **P** | Morris 水迷宫 | 平台中心 |
| **T** | Barnes 迷宫 | 目标洞 |

把标记拖到真实位置，指标立即更新。点 **保存** 保留修改。

恐惧条件化的这张卡片显示的是运动曲线，以及僵直片段、基线和 CS 时段（见[僵直](../principles/metrics.md#freezing)）。

### 序列

部分结果带有序列，可在组间分析中作为时间进程来分析：

- 旷场：每个时间段的距离和中央区时间；
- 恐惧条件化：每个 CS 和每个时间段的僵直；
- 水迷宫（手动录入）：每个试次的潜伏期；
- 平衡木：每个试次的通过时间；
- 糖水偏好：每天的偏好；
- 双臂老虎机任务：反转前后的选择，以及整场的选择图。

### 序列与标签

文本形式的结果：Y 迷宫的进臂序列（`ABCACB…`）、T 迷宫和十字迷宫的进臂序列、Barnes 迷宫的访问洞序列和搜索策略，以及 T 迷宫的首次选择。

### 已录入的数值

手动录入和导入原始值的结果，会显示录入的内容。**编辑数值** 重新打开表单。

### 分析设置

视频结果有和设置页相同的区域与阈值设置。修改后，所有指标都会根据已保存的位置立即重算，不需要视频，也不会重新追踪。常见用法：

- 看中央区时间对中央区大小有多敏感；
- 十字迷宫的开放臂方向设错了，改过来；
- 分析完成后再填入恐惧条件化的 CS 起始时间；
- 把分析窗口缩短到前 5 分钟。

设置按每条结果单独保存。要对许多动物做同样的修改，需要逐条修改，或者在分析后续视频之前就设好。

### 详细信息

**动物编号**、**组别**、**性别**、**阶段**、**天**、**试次**、**日期** 和 **备注** 都可以修改，例如更正组名的拼写。这张卡片还显示来源（视频、手动或导入）、文件、运行文件夹，以及创建和更新时间。

**从组间分析中排除** 会保留这条结果，但不纳入统计和图表，并可以填写原因，例如*从迷宫上掉落*、*追踪丢失*。在组间分析中打开 **包括已排除的记录** 可以重新显示它们。这比直接删除更稳妥。

### 方法

**这些数值是如何计算的** 给出该范式的方法说明、每个已显示指标的定义，以及所用参数：中央区比例、进入标准、僵直阈值、分析窗口等。可以直接用在论文的方法部分或实验记录里。

### 保存、还原与删除

对详细信息、设置或标记的修改，会先作为草稿保存。底部栏显示 **有未保存的更改**，可选 **还原** 或 **保存**。

**删除结果** 把这条结果从结果库中删除。视频结果的运行文件夹中的追踪文件会保留。开始页会把这个文件夹计为尚无结果的追踪记录，用 **生成结果** 可以重新生成。设置和标记会恢复为默认值，需要重新检查。
