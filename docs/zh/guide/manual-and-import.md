# 手动录入与导入表格

不是每个范式都从视频打分，也不是每个实验室都在 RodentFlow 里分析视频。人工评分或其他软件得到的数值可以手动录入或导入。它们生成的结果和视频追踪的结果格式相同，在组间分析里可以一起使用。

## 手动录入

在 **新实验** 卡片中选好实验范式，点 **录入数值**（双臂老虎机任务为 **录入试次**）。表单分三部分：

1. **动物信息**：动物编号、组别、性别，以及该范式用到的阶段、天或试次。
2. **测量值**：该范式的原始数值。必填项有标记，App 会列出还缺哪些。
3. **结果**：派生指标，边输入边重新计算，例如由新、旧物体探索时间算出辨别指数，由瓶重算出糖水偏好。

有些范式按行录入，例如每个试次、每天、每个 CS 或每一步一行。用表格下方的按钮添加行，App 根据所有行计算这只动物的数值。

| 实验范式 | 需要录入 | App 计算 |
|---|---|---|
| 旷场 | 总距离、中央区时间、测试时长、进入中央区次数、潜伏期 | 中央区时间 %、平均速度 |
| 高架十字迷宫 | 开放臂和闭合臂时间（必填）、中央区时间、进入次数、距离 | 开放臂时间 %、开放臂进入 %、总进臂次数 |
| 明暗箱 | 明箱时间和测试时长（必填）、穿箱次数、进入暗箱潜伏期 | 暗箱时间、明箱时间 % |
| 埋珠实验 | 笼内玻璃珠数、被掩埋数（≥ 2/3 覆盖）、部分掩埋数、时长 | 掩埋 % |
| 糖水偏好 | 每天：糖水瓶和清水瓶的起始、结束重量，漏液对照，小时数。体重可选。 | 偏好（合并及日均）、每日摄入量和每公斤摄入量 |
| Y 迷宫 | 进臂序列，如 `ABCABACB` | 进臂次数、交替次数、自发交替率 |
| T 迷宫 | 首次选择（左/右）、各臂进入次数、选择潜伏期 | 首选右侧 %、总进入次数 |
| 新物体识别 | 新物体和熟悉物体探索时间、探索次数、排除标准 | 辨别指数、识别指数、探索不足标记 |
| Morris 水迷宫 | 每个试次：逃避潜伏期、路径长度、游泳速度。探索测试：目标和对侧象限 %、穿越次数。 | 试次平均值、找到平台的试次 % |
| Barnes 迷宫 | 每个试次：初次潜伏期、初次和总错误数、路径长度。探索测试：目标象限 % | 试次平均值 |
| 恐惧条件化 | 全程和基线僵直 %。每个 CS：CS 期和 CS 后的僵直 %。 | CS 期平均僵直、每个 CS 的僵直 |
| 平衡木 | 每个试次：通过时间、失足次数、是否跌落。平衡木标签和宽度。 | 平均时间、每试次失足次数、跌落 % |
| 步态分析 | 每一步：左右侧、后肢和前肢步长、步宽、前后爪重叠距离。跑道时长和距离可选。 | 平均值、后肢步长变异系数、左右不对称性、步频、速度 |
| 条件性位置偏好 | 配对侧和非配对侧箱时间（必填）、中间箱时间、配对箱进入次数 | 偏好分数（配对 − 非配对）、配对侧 % |
| 双臂老虎机任务 | 每个试次：选择、是否获奖，可选奖励概率和反应时 | 赢-留、输-换、切换率、高价值选择、Q-learning 拟合 |

每个指标的定义见[各范式页面](../assays/index.md)。手动录入的结果保存后，可以在结果页用 **编辑数值** 修改。

## 导入表格

在新实验卡片中点 **导入表格**，在导入界面里：

1. 选择表格对应的 **实验范式**。
2. 可选：填写 **没有组别列时使用的组别**。
3. 点 **选择文件（CSV、TSV、JSON）**。
4. 查看预览，然后点 **导入**。

**〈范式〉的 CSV 模板** 会生成一个带有该范式所需列名的空 CSV，在电子表格软件里填好后再导入。

::: tip Excel 和 Numbers 文件
`.xlsx` 和 `.numbers` 文件不能直接读取，请先导出为 CSV（文件 › 导出或另存为 › CSV）。
:::

### 支持哪些表格格式

App 自动识别以下四种格式。

**1. 每只动物一行，每个指标一列**，这是最常见的格式。

```csv
编号,组别,性别,总距离 (m),中央区时间 (%),进入中央区次数
WT01,WT,雄,28.83,19.0,17
KO01,KO,雌,22.10,12.4,11
```

**2. 原始测量值**，字段与手动录入相同。每只动物一行，范式需要按行录入时则每个试次、每天或每一步一行。App 按与手动录入完全相同的方法计算指标。

```csv
subject,group,day,sucrose_start,sucrose_end,water_start,water_end,sucrose_leak,water_leak
Con01,Control,1,185.63,180.55,193.44,193.29,0.1,0.1
Con01,Control,2,180.26,175.23,192.09,191.94,0.1,0.1
```

**3. 长格式**：每只动物的每个指标一行，有一列 `metric`（或 `measure`、`variable`、`parameter`）和一列 `value`（或 `result`、`score`）。

```csv
subject,group,metric,value
V01,Vehicle,novel_time_s,23.5
V01,Vehicle,familiar_time_s,16.4
```

**4. 双臂老虎机的逐试次数据**，包含 `choice` 和 `reward` 列，可选 `p_left`、`p_right` 和 `rt`。选择可以写成 `L`/`R`、`left`/`right` 或 `0`/`1`。

RodentFlow 导出的 JSON 文件（单条结果或结果列表）会原样导入，并保留各自的实验范式。1.0 版的 `summary.json` 也会自动转换。

### 列名如何匹配

比较列名时不区分大小写，并忽略空格和标点。`Total distance (m)`、`total_distance_m` 和 `distance_m` 都对应同一个指标。

| 信息 | 可用的列名 |
|---|---|
| 动物 | `subject`、`subject_id`、`mouse`、`mouse_id`、`animal`、`animal_id`、`id`、`rat`、`name`、`编号`、`动物编号`、`小鼠编号`…… |
| 组别 | `group`、`condition`、`genotype`、`treatment`、`cohort`、`组别`、`分组`、`处理`、`基因型` |
| 性别 | `sex`、`gender`、`性别`；取值 `M`/`F`、`male`/`female`、`♂`/`♀`、`雄`/`雌` |
| 天 | `day`、`session_day`、`天`、`天数` |
| 试次 | `trial`、`trial_number`、`run`、`试次` |
| 阶段 | `phase`、`stage`、`session`、`test`、`block`、`阶段`；`probe`、`acquisition`、`pre-test`、`探索测试` 等取值会自动对应到 App 的阶段 |
| 日期 | `date`、`experiment_date`、`test_date`、`日期`、`实验日期` |
| 备注 | `notes`、`comment`、`备注` |
| 指标 | 英文的指标键名、指标名称，或名称加单位。App 以中文运行时，App 里显示的中文名称也可以，如 `总距离 (m)`。 |

其他数值列会以原列名作为*自定义指标*保留，不会丢失，在组间分析里可以像其他指标一样使用。

### 数字与缺失值

- 根据表头行自动识别逗号、分号和制表符分隔。
- 分号分隔的文件里，小数逗号（`12,5`）读作 12.5。
- 空单元格和 `NA`、`NaN`、`N/A`、`-`、`null` 视为缺失。
- `yes`/`no`、`true`/`false` 读作 1/0，末尾的 `%` 会被忽略。
- 文件按 UTF-8 读取，读不出时尝试 Windows 编码，以兼容较早导出的文件。

### 导入预览

保存之前，预览会显示：

- **格式**：识别出的是哪种格式；
- 统计出的 **记录数**、**动物数** 和组别；
- **已识别的列**：每一列及其对应的指标或字段；
- **已忽略的列**：没有匹配到任何内容的文本列；
- 警告，例如缺少组别列；
- **前几条记录**：前几条将要保存的结果。

如果某一列没有被识别，请在文件里把它改成 App 中显示的指标名称，或者使用 CSV 模板。
