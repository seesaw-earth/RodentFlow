# 分析一段视频

每个视频范式都走同样的路径：**范式 → 动物 → 标定 → 追踪 → 回看 → 结果**。本页逐步说明；各[范式页面](../tasks/)补充每个测试特有的内容。

## 1 · 范式、视频和毛色 {#start}

- **iPhone 和 iPad**：在**范式库**（或首页的**新建分析**）里选测试，再从相册或“文件”选视频。用“视频遮挡”做好的遮挡副本可以直接用于本次分析。
- **Mac**：用**新建任务…**建立任务，再把视频拖进去。一段视频是一只动物的一次实验。

姿态范式需要选**毛色**：单鼠范式选*深色*（默认）或*白色*；双鼠范式选*两只深色*或*一黑一白*。毛色决定模型；四个模型给出相同的 6 个关键点，分析方式也相同。所用模型会写进每个导出文件。见[模型](../models.md#coat)。

## 2 · 动物信息 {#animal}

| 字段 | 说明 |
|---|---|
| **动物编号** | 同一只动物的每次实验都用同一个编号。组间比较时，同一阶段内一只动物的多次实验先取平均，所以 *n* 是动物数。 |
| **组别** | 例如 `WT`、`KO`、`Vehicle`。各动物的拼写必须一致。像 `WT-Veh` 这样的组名之后可以拆成两个因素（基因型 × 处理）。 |
| **性别** | 在组间比较中可作为第二个因素或筛选条件。 |
| **阶段、天、次** | 有这些设置的范式才显示：训练与测试、习得与探查、前测与后测、学习曲线的天数。同一动物的前测和后测会自动配对。 |
| **日期** | 视频带日期时自动读取，可以修改。 |

## 3 · 标定 {#calibration}

在一帧画面上把带标签的手柄拖到场地上，并输入实际尺寸（厘米）。拖动时会出现放大镜。

| 场地 | 手柄 |
|---|---|
| 方形场地（旷场、明暗箱、位置偏好、恐惧箱 …） | **1–4** 放在地面内侧的四个角。位置会做透视校正，相机略有倾斜也没关系。 |
| 圆形场地（水迷宫、Barnes 迷宫、零迷宫） | **C** 放在圆心，**R** 放在池壁或边缘。 |
| 十字、Y 和 T 迷宫 | 中心交叉点和每条臂的末端。 |
| 范式中的物体 | 杯子（**L**、**R**）、物体（**A**、**B**）、平台（**P**）、庇护所（**S**）、食物（**F**）、目标洞（**T**）、四角的珠子（**1–4**）、提示卡（**Q**）……屏幕上和范式页面上都有名称。 |

分析设置和标定在一起：

- **只识别场地范围**（默认打开）：只把场地及 5 %、12 % 或 25 % 的外扩交给模型，画面其余部分不参与。之后若把标定拖出了已识别的范围，App 会提示重新识别。
- **分析起点和时长**：例如从放鼠的时刻到测试截止。**时间段**决定时间进程的分段。
- **帧**：每帧识别，长录像可每 2 帧或每 3 帧一次。快速行为（扑咬、头部扫视）需要每帧识别。
- **范式参数**：区域大小、阈值、哪一侧是配对侧或深侧、CS 或刺激的时间。默认值来自文献，各范式页面都有列出。

在 Mac 上，**用于该任务的所有视频…**把一次标定应用到同一机位拍摄的所有视频；任务里新加的视频也会从上一次标定开始，之后的动物通常只需快速检查。

## 4 · 追踪 {#tracking}

点**开始识别**（Mac：**分析该视频**）。视频在本机逐帧读取。追踪时边做边存，中断后从停下的地方继续；在 Mac 上，长录像每隔几秒写盘一次，你在标定或复核其他视频时，多段视频可以排队等待分析。追踪（最慢的一步）只做一次：区域、阈值和分析时段之后都可以修改，结果**无需重新追踪**就会更新。

## 5 · 回看 {#review}

回看页播放视频，动物身上画出关键点（双鼠时 **A** 蓝、**B** 红），下面的时间轴每种评分行为一行：进入、嗅探、头探、冻结、攻击等。点一段即可跳到那里。

- **标记**。需要检查的时刻在时间轴上标出：*超出标定范围*（点落在场地之外，逐帧数据里也有标记），双鼠时还有*疑似交换*和需要核对身份的时刻。
- **身份**。如果从某一帧起 A 和 B 交换了，点**从这里交换 A / B**，结果立即重新计算。
- **手动标记**。边看边按*开始*和*结束*标记行为，可以是 App 已有的行为，也可以自己命名（例如“理毛”）。对 App 也会评分的行为，在你复核过的范围内给出与人工标记相比的精确率、召回率、F1 和起点误差。手动标记随行为片段一起导出。
- **排除一次实验**。标记为排除并写明原因；原因会导出，这次实验不进入组间统计。

## 6 · 结果和导出 {#results}

每次实验的结果页列出每个指标及其定义，画出轨迹和热图，并显示时间进程。导出内容见[结果与导出](./results.md)。

## 视频遮挡 {#cover}

**视频遮挡**（首页，或分析中的“遮挡视频的固定区域…”；Mac 在工具里或实验的右键菜单里）在画面的固定位置贴上色块，盖住会干扰追踪的东西：反光、电线、池边的实验者。色块可以是矩形、圆角矩形、椭圆或多边形，颜色自选或取周围的颜色。保存时只处理一次视频，另存一份副本，时间戳、分辨率、方向和拍摄日期都与原视频一致；原视频不改动。

## 质心法 {#classic}

质心法就是 RodentFlow 1.x 的追踪方法，原样保留：从整段视频的帧中学习空场地，减去背景，以**每秒 10 个样本**跟踪**身体中心**，不用神经网络。它涵盖十个测试：旷场、高架十字迷宫、明暗箱、Y 迷宫、T 迷宫、新物体识别、Morris 水迷宫、Barnes 迷宫、恐惧条件化和条件性位置偏好。用 RodentFlow 1.x 做的结果照常打开和分析。

在范式库的**质心法**组里选择（每个测试也链接到它的姿态版本）。流程相同：设置场地形状和尺寸，看 10 秒预览，放置手柄，运行完整分析，查看结果。因为它跟踪的是身体中心，需要鼻尖或头部的指标（物体嗅探、头探、头朝向）来自姿态版；同一研究请始终使用同一种方法。1.x 的详细说明保留在[旧版本](../archive/guide/video-analysis.md)里。
