# 怎样拍出好追踪的视频

大多数追踪问题要在拍摄时解决，而不是在 App 里。花十分钟布置好装置，可以省下之后的几个小时。正式实验之前，先在真实装置里录一段短视频分析一下。

## 检查清单 {#checklist}

| | 怎么做 | 为什么 |
|---|---|---|
| **相机** | **正上方**俯拍，固定在动物之间不会移动的支架上。（悬尾：正对装置前方。） | 厘米是在地面平面上测量的。相机固定时，整批视频可以共用一次标定。 |
| **取景** | 让场地**占满大部分画面**，四周留一点边距。 | 每厘米像素越多，关键点越准。边距让小鼠探头越过迷宫边缘时鼻尖仍在画面内。 |
| **对比** | 浅色地面上的深色小鼠，或深色地面上的白鼠，并在 App 里选好**毛色**。 | 毛色决定使用针对该毛色训练的模型。 |
| **光线** | **均匀、柔和**；没有移动的阴影；水面、玻璃或亚克力上没有反光。灰度和红外视频都很好用。 | 阴影和反光可能被当成动物的一部分。 |
| **曝光** | 锁定曝光和对焦。在 iPhone 相机里长按场地，直到出现 **AE/AF 锁定**。 | 自动曝光会在小鼠走到镜头下时改变整个画面的亮度。 |
| **手和盖子** | 让它们不出现在评分时段里，或把分析起点设在之后。 | 评分时场地里任何移动的东西都可能被当成动物。 |
| **固定干扰** | 分析前用**视频遮挡**盖住（反光、电线、池边的实验者）。 | App 另存一份遮挡后的视频，时间戳不变；原视频不改动。 |

## 帧率、分辨率和时长 {#format}

- **帧率**：大多数范式 25–30 帧/秒即可。快速事件（攻击扑咬只有 100–200 ms；T 迷宫选择点的头部扫视）至少用 25 帧/秒，并逐帧识别。
- **分辨率**：1080p 足够。4K 也可以；在 iPhone 和 iPad 上，很大的画面会按较小尺寸解码，仍大于模型输入尺寸。
- **时长**：没有固定上限。长录像需要更久，边做边存，暂停或重启都不会丢失进度。
- **格式**：普通的 MP4 或 MOV（H.264 或 HEVC）。打不开的文件可以转成 H.264 MP4，例如用免费的 [HandBrake](https://handbrake.fr/)。

## 同一场地里的两只小鼠 {#two-mice}

两只小鼠**毛色、体型不同或有标记**时，身份最可靠。毛色相同时，用记号笔在尾巴上画一道，或在背上染一块，给 App 一个可以分辨的特征。一黑一白时，毛色选*一黑一白*。居住者–入侵者实验请**在放入入侵者之前开始录像**：只有居住者的那段用来识别居住者，并找到入侵者放入的时刻。

## 个别范式的注意事项 {#tasks}

- **高架十字和零迷宫、跳台、视觉悬崖**：边缘四周留出空间，小鼠探头时鼻尖仍在画面内。
- **水迷宫**：把水弄成不透明、与小鼠颜色对比明显，避免灯光在水面反光。探查测试前先标出平台位置。
- **埋珠**：相机固定在笼子正上方，测试中不要移动，光线保持不变；珠子与垫料对比越强越好。放鼠之前的画面是最好的参照帧。
- **恐惧条件化和逼近刺激**：箱内光线保持不变；灯光线索一亮会让整个画面变化片刻。
- **明暗箱**：用红外相机可以在暗室里也看到小鼠。暗室有盖又没有红外时，小鼠进去后就看不见了；质心法可以把这段时间计为在暗箱（“看不到小鼠时计为在暗箱”）。
- **新奇抑制摄食、被动回避、跳台**：分析起点设在放鼠或开门的时刻。
- **透过透明底板拍摄的旋转实验**：打开*从下方拍摄*，避免左右颠倒。
- **多格悬尾**：正对装置前方拍摄，所有格子都在画面内；容易爬尾的品系使用防爬管。
- **质心法**：空场地背景从整段视频的帧中学习，所以小鼠必须在某个时候移动；完全不动的小鼠无法与地面区分。

## 文件命名和视频存放（Mac） {#files}

- **文件命名为 `动物编号_YYYY-MM-DD`**，例如 `M01_2026-10-17.mp4`。Mac 从文件名读取日期（`2026-10-17`、`2026_10_17`、`2026.10.17` 或 `20261017`），其余部分作为动物编号，导入表会自动填好。
- **导入前把视频放到最终的文件夹**。Mac 就地读取视频，从不修改。之后移动或改名时，用**定位视频**重新关联。
- 只使用你有权使用的视频，未发表的录像请遵守所在单位的数据政策。
