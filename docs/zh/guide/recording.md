# 怎样拍出好追踪的视频

追踪器把每一帧和“空场地”的图像比较，以此把动物和场地区分开（见[追踪原理](../principles/tracking.md)）。场地里除了动物以外的任何变化都可能被误认为动物；动物颜色和地面接近，又会很难被找到。大多数追踪问题要在相机这一端解决，而不是在 App 里。

## 检查清单

| | 怎么做 | 原因 |
|---|---|---|
| 相机 | 装在场地**正上方**，用支架固定，换动物时不要动 | 厘米是在地面平面上计算的。相机固定，就能用 **使用上次设置** 沿用校准。 |
| 构图 | 让场地**尽量占满画面** | 分析时视频长边会缩到 192 像素。场地在画面里越小，每厘米的像素就越少（见下文）。 |
| 对比度 | 深色动物配浅色地面，或白色动物配深色地面 | 追踪器看的是与背景差异的大小，两种明暗关系都可以，但必须有差异。 |
| 光照 | **均匀**的漫射光；没有移动的阴影；水面、亚克力不反光 | 阴影和反光引起的画面变化和动物一样。 |
| 曝光 | 锁定曝光和对焦。在 iPhone 相机里长按场地，直到出现 **自动曝光/自动对焦锁定**。 | 自动曝光会在深色动物经过画面时改变整幅画面的亮度。 |
| 开始与结束 | 评分时段内手、盖子和实验人员不要入画；或者用分析窗口跳过这段时间 | 评分时段内场地里任何移动的东西都可能被当成动物。 |
| 单只动物 | 每个场地一只动物 | 追踪器只跟踪一只动物。 |

## 每厘米多少像素？

追踪前，每一帧都被缩放到长边 192 像素。只要场地在画面里不太小，这对小鼠身体来说足够。

| 场地在 16:9 画面中的大小 | 缩放后每厘米像素数 | 意味着 |
|---|---|---|
| 40 cm 旷场，占画面宽度 60 % | 约 2.9 像素/cm | 小鼠身体约 25 像素长，很充裕 |
| 70 cm 十字迷宫，占画面宽度 55 % | 约 1.5 像素/cm | 时间和进臂次数准确，但总距离偏高（见[验证](../principles/validation.md)） |

在能拍全场地的前提下，构图越紧越好。把手机转到让画面长边对着场地长边，也有帮助。

## 视频格式、分辨率和时长

- **格式**：iPhone 能播放的都可以，如 H.264 或 HEVC 编码的 MOV、MP4。其他相机拍的视频可以通过隔空投送、“文件”App 或 U 盘传到手机上。
- **分辨率**：720p 或 1080p 足够。4K 也可以，但解码更慢，因为每一帧最后都会缩到 192 像素。
- **帧率**：不限。App 按视频里记录的时间戳每秒取 10 帧，所以 25、30、60 fps 得到的时间基准一样。
- **时长**：没有固定上限。视频越长分析越久，中途可以暂停和继续。

## 动物总得动一动

“空场地”的图像是用均匀分布在整段视频里的 21 帧算出来的。只要动物在大多数帧里都在别处，地面就能露出来，背景就是对的。有两种情况需要注意：

- **动物在同一处待了很长时间**（十字迷宫的闭合臂、长时间僵直、水迷宫的平台上）。如果不处理，静止的动物会被算进背景，留下一个“幽灵”。追踪器会自动识别并修补（[原理](../principles/tracking.md#resting-animal-repair)）。
- **动物从头到尾一动不动**，无法和背景分开。任何基于背景的方法都追踪不了这种视频。

## 各实验范式的建议

- **明暗箱**：如果暗箱有盖，动物进入暗箱后就看不见了，这是正常的。打开 **看不到小鼠时计为在暗箱** 后，这些样本计入暗箱时间。只校准能看到的底面，并相应设置明箱长度。
- **水迷宫**：把水调成不透明，颜色要和动物形成对比。避免顶灯在水面上反光。探索测试时平台看不见，要在习得阶段先记下平台位置。
- **Barnes 迷宫**：光照要亮且均匀。洞是暗的，深色小鼠探洞时头会“消失”在洞里，所以洞区设得比洞本身大。
- **新物体识别**：物体不要投下长长的影子。物体中心在校准时标记。
- **恐惧条件化**：整个过程中箱内光照保持不变。如果 CS 是在开始时点亮的灯光，所有像素会同时变化，在那一瞬间看起来像动物在动。被动物踢动的垫料也会计为运动。
- **一个画面里有几个场地**：每次分析只看校准的那个场地，所以同一段视频可以按场地分别分析，每次单独校准。

## 能剪就剪

如果视频开头是把动物放进场地的过程，可以在导入前先在“照片”里剪掉，或者在分析窗口里把 **起始于** 设为希望开始评分的那一秒。水迷宫和 Barnes 迷宫对应的是 **试次在视频中的起点**。
