# 组间比较

在 iPhone 或 iPad 上打开**组间**，在 Mac 上打开任务的**组间比较**。两者用同一套代码，同样的实验得到同样的统计结果。姿态、质心法、多格悬尾和手动录入的结果都可以参与。

## 1 · 选择比较什么 {#choose}

1. **范式和指标**。列出这个范式的所有指标及单位。
2. **设计。**

| 设计 | 用于 |
|---|---|
| **组间比较** | 每只动物一个值，各组并排（最常见） |
| **按天** / **按实验次数** | 学习曲线：同一批动物多天或多次的数据 |
| **时间进程** | 一次实验内按时间段的指标 |
| **阶段间变化** | 每只动物两个阶段之差，例如测试 − 前测（CPP 分数、跳台测试与训练） |
| **配对指标** | 同一动物的两个指标，例如新物体与熟悉物体 |

3. **筛选**。阶段、天、次或实验次数，以及性别。除非你选择合并，不同阶段永远不会混在一起。
4. **第二个因素**（可选）。性别，或按分隔符拆分组名：`WT-Veh`、`WT-Drug`、`KO-Veh`、`KO-Drug` 拆成基因型 × 处理。
5. **协变量**（可选）。同一动物的另一个指标，例如新奇抑制摄食的家笼摄食量或水迷宫的游速。

## 2 · 看结果 {#result}

- **n 是动物数**。所选阶段内一只动物的多次实验先取平均。被排除的实验不参与。
- **检验与设计匹配**：两组用 Welch t 检验或 Mann–Whitney；三组及以上用单因素方差分析加 Tukey–Kramer，或 Kruskal–Wallis 加 Dunn–Holm；动物内配对用配对 t 检验或 Wilcoxon；跨天或跨次用混合方差分析（Greenhouse–Geisser 校正）；有第二个因素时用双因素方差分析（Type III）；有协变量时用 ANCOVA。每个检验都给出效应量及其 95 % 置信区间。详见[统计方法](../principles/statistics.md)。
- **前提检查**（每组和残差的 Shapiro–Wilk、Brown–Forsythe 方差齐性）只作为建议显示；App 不会自行更换检验。
- **有截止时间的潜伏期**（水迷宫逃避、被动回避、跳台、视觉悬崖、新奇抑制摄食、攻击潜伏期）另给 **Kaplan–Meier 曲线和 log-rank 检验**，正确处理到截止时仍未发生事件的动物。
- **是 / 否指标**（是否跳下、是否进入暗室、首次是否选深侧、是否攻击）另给 **Fisher 精确检验**或卡方检验。

## 3 · 图 {#figure}

屏幕上的图就是导出的图。可选点加均值、柱加点、箱线加点或小提琴加点；误差线为 SEM、SD 或 95 % CI；显著性括号用星号或精确 p 值；固定 Y 轴范围；以及适合打印的灰度模式。每只动物都会画出。尺寸按期刊栏宽（85、114 或 174 mm），整张图统一字号。

姿态范式可以用**导出任务图集**把每只动物的轨迹和热图画成多面板图，每组一行，**共用同一色标**并附色标条，另有每组的平均热图。

## 4 · 导出 {#export}

组间导出是一个英文文件夹：

| 文件 | 内容 |
|---|---|
| `figure.pdf` / `.svg` / `_300dpi.png` | 图 |
| `figure_source_data.csv` | 每只动物一行，另有每组的 n、均值、SD、SEM、误差线端点、中位数和四分位数 |
| `figure_legend.txt` | 图注草稿：图型、误差线、每组 n、检验、统计量、p、效应量、星号含义 |
| `stats_report.csv` | 每个检验、项、两两比较、效应量和前提检查各一行 |
| `methods.txt` | 统计部分的方法学段落 |
| `prism_table.txt` | 可直接粘贴进 GraphPad Prism（Column 表或 Grouped 表） |
| `long_format.csv` | 每只动物一行，含组、因素、性别和协变量，供 R 或 Python 使用 |
| `summary.txt`、`comparison_result.json`、`README.txt` | 摘要、完整结果和文件说明 |
