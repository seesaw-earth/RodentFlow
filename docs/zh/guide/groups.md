# 组间分析

**组间分析** 标签页比较同一实验范式的已保存结果在各组之间的差异，例如 WT 与 KO、溶媒与药物。它使用该范式的全部结果，不论来自视频、手动录入还是导入。顶部的快捷标签（**实验范式 · 分析 · 组别 · 图表 · 统计**）可以跳到对应卡片。

如果还没有任何结果，页面会提供 **前往“实验”** 和 **导入数据**。

## 1. 实验范式

选择实验范式，只列出有已保存结果的范式。有多个阶段的范式会预选通常要分析的阶段：新物体识别和位置偏好为“测试”，水迷宫和 Barnes 迷宫为“习得”，恐惧条件化为“线索测试”。除非你明确选择，不同阶段不会混在一起。

## 2. 分析

### 设计

设计决定了“一个数据点”是什么，以及用哪种检验。

| 设计 | 每个数据点 | 典型问题 | 何时可用 |
|---|---|---|---|
| **组间比较** | 每只动物一个值（多个阶段先平均） | KO 小鼠的运动距离是否比 WT 少？ | 始终可用 |
| **跨天比较** | 每只动物每天一个值（当天试次平均） | 两组学习水迷宫的速度是否不同？ | 结果中至少有 2 个不同的天 |
| **时间进程** | 每只动物每个序列点（时间段、CS、试次）一个值 | 三次 CS 的僵直是否不同？ | 结果带有序列 |
| **配对测量** | 每只动物两个测量值 | 小鼠探索新物体是否多于熟悉物体？ | 范式有天然的配对 |
| **阶段间变化** | 每只动物一个差值 *到 − 从* | 条件化是否改变了位置偏好（测试 − 前测）？ | 结果中至少有 2 个阶段 |

*配对测量* 可用的配对有：新物体 vs 熟悉物体（新物体识别）、配对侧 vs 非配对侧（位置偏好）、糖水 vs 清水摄入（糖水偏好）、目标象限 vs 对侧象限（水迷宫、Barnes 迷宫）、基线 vs CS 期僵直（恐惧条件化），以及开放臂 vs 闭合臂时间（高架十字迷宫）。

### 测量指标与筛选

- **测量指标**、**序列** 或 **比较**：要分析的内容，取决于所选设计。
- **从 → 到**：*阶段间变化* 使用的两个阶段。
- **阶段**（或 **平衡木**、**场次 / 区组**）：只分析某一个阶段。选 *全部* 会合并所有阶段；有动物的多个阶段被平均时，App 会说明。
- **统计**：**参数检验** 或 **非参数检验**。
- **比较**（三组及以上）：**两两比较**；或者第一组是对照、只关心与对照的比较时，选 **与第一组比较**。
- **各组与……比较**：用于有机会水平的指标，例如辨别指数与 0 比较，识别指数、糖水偏好、位置偏好和高价值选择与 50 % 比较，象限时间与 25 % 比较。
- **包括已排除的记录**：重新纳入标记为 *从组间分析中排除* 的结果。

## 3. 组别

组别取自每条结果的 **组别** 字段，拼写必须一致。在这张卡片里：

- 第一组被视为**对照组**。**▲ ▼** 调整顺序，这也是图中的顺序；
- 开关决定纳入或去掉某一组；
- 点颜色圆点切换颜色。配色使用对色盲友好的调色板（Okabe–Ito），对照组默认为灰色。顺序、颜色和是否纳入按范式记住。

## 4. 图表

每张图都把每只动物画成一个点，读者可以直接看到数据的分布和 n。

- **样式**：**柱状 + 散点**、**箱线 + 散点** 或 **均值 ± SEM**，用于 *组间比较* 和 *阶段间变化*。
- *跨天比较* 和 *时间进程* 画学习曲线或时间进程：每个水平上的组均值 ± SEM，细线是每只动物。
- *配对测量* 为每只动物画一条连线，连接它的两个值。
- 显著性括号使用校正后的 p 值：* p < 0.05，** p < 0.01，*** p < 0.001，**** p < 0.0001。打开 **显示不显著的比较（ns）** 会把其余比较也画出来。

**导出图表（PNG）** 保存高分辨率图片（屏幕分辨率的 3 倍），可用于幻灯片或论文草稿。

## 5. 统计

统计卡片给出：

- 用文字描述的**方法**，例如“单因素方差分析，事后采用 Tukey–Kramer HSD 进行两两比较”，可以直接写进方法部分；
- **总体检验**的统计量、自由度、p 值和效应量；
- **两两比较**及校正后的 p 值；
- 选择了的话，各组与机会水平比较或组内配对比较的结果；
- **描述统计（n = 动物数）**：n、均值 ± SEM、SD、中位数和四分位数；
- **备注**：例如哪些动物的多个阶段被平均、哪些已排除的记录未纳入、哪些纳入的记录带有质量提示、哪些动物因缺少某一天而未进入方差分析。

检验如何选择、每种检验如何计算，见[统计方法](../principles/statistics.md)。

## 良好实践

- **n 是动物数。** 同一只动物的多个试次和阶段在检验前先平均。不要把同一只动物用两个编号录入。
- **在看统计结果之前就定好排除标准**，例如追踪低于 90 % 或最少探索时间。用“排除”并写明原因，而不是删除结果。
- **不同阶段分开分析。** 探索测试和探索测试比，测试和测试比。如果关心的是变化本身，用 *阶段间变化*。
- **参数还是非参数？** 每组样本少（n < 8），且数据明显偏态或有上下限时，非参数检验更稳妥，例如被截断在试次最长时间的潜伏期，或接近 0 或 100 的百分比。要在看到 p 值之前做出选择。
