# 常见问题排查：Mac 与姿态追踪

## 导入

以前能用的实验提示“无法打开视频”

文件被移动、重命名、删除，或位于未连接的外置 / 网络硬盘上。请连接硬盘或把文件放回原处。否则，把这次实验从项目中移除后重新添加视频（并重新检查标定）。

视频无法导入或没有画面

可能是 macOS / iOS 不支持该编码。请用 [HandBrake](https://handbrake.fr/) 转成 H.264 MP4（如“Fast 1080p30”预设）后重试。若普通的 H.264 MP4 仍然失败，请[反馈给我们](/zh/support)。

“文件名和文件中没有日期” / 日期不对

导入前把日期写进文件名（`M01_2026-10-17.mp4`），或在导入表格中手动填写。整批视频同一天录制时，用“全部使用第一行的日期”最方便。

“M01 在此任务中已有第 1 次实验”

同一任务中，每只小鼠的实验次数必须唯一。请改用下一个编号（表格会给出建议），或检查是否重复导入了同一段视频。

某次实验在“缺信息”中，无法分析

打开它，在“实验信息”中补全小鼠编号、实验日期和实验次数。早期版本导入的实验可能需要补一次。

## 分析

“此版本未安装分析模型”

你使用的版本编译时没有包含 Core ML 模型。App Store 版本已内置模型。若是自行编译，请运行 `git lfs pull` 让模型权重成为真实文件，然后重新编译（见[从源码编译](/zh/source#build)）。“工具 › 模型”可查看安装情况。

“请先标定场地”（RodentFlow）

RodentFlow 追踪器需要先知道场地位置。进入“校准”，放好手柄并保存后再分析。

分析很慢

姿态追踪逐帧进行；视频长、分辨率高时需要较长时间，Intel Mac 尤甚。让队列在后台运行（你可以继续做别的），关闭其他占用资源的 App，并接通电源。在 iPhone/iPad 上，若不需要快速头部动作，长视频可每 2–3 帧识别一次。

分析中断，或 Mac 进入了睡眠

点“继续分析”——已完成的分段会保留。“分析失败”会显示原因；“重试”会从头开始。若某段视频反复失败，可尝试重新编码。

检出率低 / 关键点乱跳

检查光照、对比度、反光以及动物是否出画。用“逐帧复核”找到问题帧。提高关键点置信度阈值可隐藏不确定的点；平滑和缺口插值（校准 › 分析时间段与预处理）能减少抖动，且无需重新追踪。

结果明显不合理（如中央区时间 0%、距离极大）

通常是标定问题：手柄放在外壁而非内壁、场地尺寸填错，或分析时间段不对。检查像素 / cm 比例和手柄位置，并把轨迹与区域对照查看。

同一段视频，RodentPose 和 RodentFlow 结果不同

这是正常的。RodentPose 使用关键点（如用鼻尖判断物体探索）；RodentFlow 使用 10 Hz 的身体质心，区域定义也不同。同一研究请固定使用一个模块。

逐帧复核时关键点被隐藏

解码画面与追踪时间戳（或画面方向）不一致，为避免误导性复核而隐藏了标点。换到相邻帧即可；原始数据不受影响。

## 多格 TST

没能自动找到格子

画面会先平均分成 6 格。请设置正确的格子数并把白色手柄拖到隔板上，或点“重新检测”。

“没有找到所有选中格子同时有小鼠……的时刻”

检查是否只选中了有小鼠的格子，在“检测设置…”中降低“最低置信度”，或使用“手动设定起点…”。浅色小鼠请把“小鼠颜色”改为“浅色小鼠 / 深色背景”。

轮廓不贴合小鼠

停止后调整分析带使其覆盖小鼠，或在“检测设置…”中修改小鼠颜色。手、袖子和阴影会干扰经典检测器；可在检测设置中导入针对你装置微调过的 YOLO 模型。

“结果”步骤变灰

自上次分析后起点、分析带、格子或时间窗已改变。点“重新分析”以更新结果。

“无小鼠”帧超过 10%

小鼠爬尾、被提前取下或离开了画面。请在原始录像中复核该格；如不符合你的标准，填写原因后排除。

## iPhone 与 iPad

识别自己暂停了

App 被切到后台或设备锁屏了。进度已保存；打开该分析点“继续识别”。识别期间请保持 App 在前台。

旧的分析无法回看或重新识别

为节省空间删除了视频副本。结果和姿态数据仍在；如需回看，请用原始视频新建一次分析。

姿态模型一直在加载

加载期间可以先导入视频和标定。若一直无法就绪，打开设置点“重新加载”；重启 App 也有帮助。

## 导出

Excel 中中文显示为乱码

通过“数据 › 从文本/CSV”以 UTF-8 编码导入，或用 Numbers 打开。列名为英文，不受影响。

任务导出中部分实验没有数值

它们的结果还在计算中。等任务页顶部的进度完成后再导出。未分析或（RodentFlow）未标定的实验没有数值。
