# 手机到 Mac 同步

iPhone 或 iPad 上完成的分析可以自动出现在 Mac 上，并归入正确的任务、组和动物。两端通过你选择的文件夹交换数据，通常放在 iCloud 云盘里；不经过任何其他服务器。

## 设置 {#setup}

1. **iPhone 或 iPad**：设置 › **Mac 同步** › **选择同步文件夹…**。在 iCloud 云盘里新建一个文件夹，例如 `RodentFlow`，就很好用。可以选择同时写入每段视频的副本（视频可能很大）。
2. **Mac**：设置（<kbd>⌘</kbd><kbd>,</kbd>）› **手机数据** › 选择同一个文件夹（选它本身或其中的 `RodentFlow Sync` 都可以）。

## 同步过程 {#how}

- 手机每完成一个分析，或你修改了它的标定、设置、动物编号或组别，都会为这个分析写一个同步包。
- Mac 在启动时、每 30 秒、切回 App 时，以及点“立即查看”时查找新的同步包。它检查每个文件的大小和校验值，等待仍在同步中的包，不导入损坏的包。
- 每个分析都复制到 Mac 自己的存储里，按任务 → 组 → 动物 → 实验（日期和实验次数）归档。手机上的新版本会**原地更新同一次实验**，保留你的复核备注。在 Mac 上删除的实验不会再次导入，除非手机又修改了它。
- Mac 用同一套代码**重新计算**每个导入的分析，并在结果页显示是否与手机一致（“与手机上的结果一致，比较了 n 项指标”），或列出不同的指标。
- 导入的实验在侧栏里标为“来自手机”。

## 同步包里有什么 {#contents}

| 分析 | 同步包内容 |
|---|---|
| 姿态 | 设置（`session.json`）、轨迹（`pose.mpt`）和标定帧 |
| 质心法 | 追踪样本、场地设置和标定帧 |
| 多格悬尾 | 完整的录像存档，格式与 Mac 相同 |

没有视频副本时，导入的实验不能在 Mac 上重新标定；它的结果、图和导出是完整的。需要时在手机上打开视频副本。
