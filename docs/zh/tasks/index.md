# 实验范式

RodentFlow 2.1 用姿态关键点从视频分析 **25 个行为测试**，另有**多格悬尾**和**仅导出姿态**（导出关键点和运动学数据，供你自行分析）。下面每个页面都说明这个测试怎么设计、为什么关键点比身体质心测得更准、每个指标的确切定义，并附一个模拟示例和相关文献。

所有范式在 iPhone、iPad 和 Mac 上都能用。范式决定追踪几只动物；单鼠范式可选深色或白色毛色，双鼠范式可选两只深色或一黑一白（见[模型](../models.md#coat)）。

## 不用视频的结果 {#manual}

埋珠、糖水偏好、平衡木、步态、双臂老虎机和自定义指标，也可以在 iPhone 和 iPad 上手动录入或从表格导入，和其他结果一样参与组间比较。见[手动录入与导入表格](../guide/manual-and-import.md)。

::: tip 关于示例图
每页的示例都是**模拟实验**：让一只模型小鼠在场地里活动，再用 App 定义的简化版本计算指标。这些图用来说明每个指标的含义，不是实验数据，也不能当作参考值。
:::
