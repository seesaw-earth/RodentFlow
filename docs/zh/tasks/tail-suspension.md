# 多格悬尾

<div class="rf-tags"><span>多格同步</span><span>iPhone、iPad 和 Mac</span><span>标准时长：6 分钟</span></div>

**同一段录像里并排悬挂的多只小鼠 · 第 2–6 分钟不动时间**

悬尾实验把小鼠倒挂 6 分钟，四周够不到任何支撑。挣扎和静止悬挂交替出现，不动时间是经典读数。RodentFlow 对**同一段录像里并排悬挂的多只小鼠**同时评分：自动找到格子，找到所有小鼠都已挂好的时刻，逐格测量运动，再把每个格子保存为一只动物的一次普通实验，所以分组、组间比较和导出与其他范式完全一样。

## 评分方法 {#measures}

| 指标 | 定义 |
|---|---|
| **第 2–6 分钟不动时间（★）** | 主要指标：这只小鼠挂上后第 2 到第 6 分钟的不动时间。同时报告第 0–2、0–6 分钟和全程。 |
| **运动量** | 每只小鼠固定运动框内的像素变化，先对齐画面抵消被动摆动，摆动不计为运动。另有两种基于轮廓的指标可供对照。 |
| **不动** | 运动量低于阈值（默认为鼠体面积的 2 %）并持续至少 1 秒。 |
| **不动片段与潜伏期** | 首次不动潜伏期；不动次数、平均和最长片段；每分钟不动时间。 |
| **运动强度** | 活动时的平均运动量，即挣扎的剧烈程度。 |

- **每只小鼠从自己挂上的时刻开始计时**，前后相差几秒挂上的小鼠也按相同的时间窗评分。
- 没有小鼠的帧（已取下、爬尾、出画）计为“无小鼠”，不计为不动；不动百分比的分母只包含有小鼠的帧。“无小鼠”帧超过 10 % 的格子会提示复核。

## 设置 {#setup}

1. 从正面拍摄，所有格子都在画面里，光线均匀，背景单一并与毛色有对比。
2. 在范式库里选**多格悬尾**（Mac 上为“悬尾实验 · 多格同步评分”），添加录像。
3. **格子：**程序自动检测格子（检测不到时先平均分成 6 格）。设置格子数，把手柄拖到格子之间的隔板上，点格子可选中或跳过。
4. **关键帧：**所有选中格子都已有小鼠并持续设定时长的第一个时刻。让扫描完整跑完，各格的运动框才能覆盖小鼠的全部活动范围。用 ±0.25 秒 / ±1 秒微调，拖动手柄让分析带覆盖每只小鼠并在上方留一点空间。
5. **结果与小鼠：**一格一行，显示不动时间和小鼠信息。实验日期只填一次，再填小鼠编号、分组、性别和实验次数；空格子取消勾选。保存。
6. 对照录像逐只复核，标记“评分无误”或“存在问题”。

之后要改设置，打开这段录像的任意一次实验，选**调整参数并重新分析**。阈值、最短不动片段和时间窗立即生效；改格子、分析带或起点需要重新分析。

::: tip 针对自己的装置校准阈值
2 % 是起始值。先人工评分 2–3 段不动程度不同的视频（例如用 [BORIS](https://www.boris.unito.it/)），然后在“结果与小鼠”里点**用人工评分校准阈值…**：填入人工评分的第 2–6 分钟秒数，找到最佳阈值并应用。整个研究使用同一阈值。
:::

## 如何解读 {#interpretation}

不动时间更准确的说法是**被动应对策略**。镇静或兴奋、运动能力、体重、性别、品系和尾部不适都会影响结果，建议配合运动能力对照一起解读，例如同一批小鼠的旷场总距离。
