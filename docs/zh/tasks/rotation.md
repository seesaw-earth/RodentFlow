# 旋转行为

<div class="rf-tags"><span>单鼠姿态</span><span>默认场地：30 cm 圆桶；按 5 分钟分段</span></div>

**单侧损伤模型 · 同侧 / 对侧整圈数**

单侧损伤或其他单侧操作后，动物常表现出偏向一侧的旋转。按身体轴向统计同侧与对侧整圈数，净旋转数用于量化左右不对称的程度，或比较不同实验条件。

## 为什么用关键点 {#why}

旋转计数需要身体轴向（尾根 → 颈部）。RodentFlow 对轴向角度累计计数完整的 360° 转圈，原地小转也能计入，不需要旋转计。

## 测量指标 {#measures}

| 指标 | 定义 |
|---|---|
| **整圈数** | 身体轴向（尾根 → 颈部）累计转过 360° 记一圈，顺 / 逆时针分开；反向回转超过 90° 时重新计数。 |
| **同侧 / 对侧** | 根据损伤侧别换算；俯拍时画面逆时针 = 动物向左转。 |
| **净旋转** | 同侧 − 对侧，及每分钟净旋转数和分段曲线。 |

阈值都是默认值，可以在分析参数里修改；每次分析实际用的数值随结果保存，并写进方法学文字。

## 设置 {#setup}

1. 选择损伤侧别；从透明底部仰拍时请打开“从下方拍摄”。
2. 每 5 min 分段统计。
3. 实验条件可在“信息”页用 + 添加为自定义标签。

各范式通用的步骤（选范式、标定、追踪、回看、导出）见[分析一段视频](../guide/video-analysis.md)。
