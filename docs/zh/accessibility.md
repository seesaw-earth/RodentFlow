# 无障碍

无障碍功能说明与问题反馈。

RodentFlow 是 macOS 原生 App。我们希望逐步改善键盘操作、文字可读性、视觉对比度及系统无障碍功能的兼容性。

::: info
**当前状态：**尚未完成独立的发布版无障碍审核。本页面不声明软件已经全面符合 VoiceOver 或 WCAG 标准。
:::

## 可使用的 macOS 功能

- 可通过“系统设置 → 辅助功能”调整对比度、鼠标和文本显示。
- 在标准文件选择器和对话框中可尝试使用键盘导航。
- 查看小尺寸视频细节时可使用系统缩放。

## 报告无障碍问题

请通过[支持渠道](/zh/support)说明界面、辅助工具、期望行为及实际表现，无需公开分享实验视频。
