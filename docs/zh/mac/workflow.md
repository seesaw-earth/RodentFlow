# Mac：完整流程

## 窗口布局 {#mac-window}

一个窗口，三栏：

- **侧栏**（左）分三部分：
  - **任务**——每个任务，展开后是它的分组；数字角标为实验数量。
  - **智能列表**——跨所有任务汇总需要处理的实验：*全部实验*、*待分析*、*待复核*、*缺信息*（缺小鼠编号、日期或实验次数）、*已排除*，以及仅在存在时显示的*未分配任务*（早期版本导入的视频）。
  - **工具**——高级工具（见[智能列表与工具](#mac-tools)）。
- **中间列表**——所选任务 / 分组的小鼠及其各次实验（有分组时按组分段），或智能列表中的实验。顶部可搜索小鼠、分组或日期。点空白处回到任务 / 分组总览。
- **右侧页面**——任务或分组总览、小鼠页，或某次实验的四个步骤。

<kbd>⌘</kbd><kbd>1</kbd> 任务 · <kbd>⌘</kbd><kbd>2</kbd> 全部实验 · <kbd>⌘</kbd><kbd>3</kbd> 工具。侧栏可用工具栏按钮隐藏。用 <kbd>⌘</kbd><kbd>+</kbd> / <kbd>⌘</kbd><kbd>−</kbd> 放大或缩小字体（或在设置 › 字体大小中选择 紧凑 / 标准 / 大 / 特大）。

## 新建与管理任务 {#mac-task}

**新建任务…**会打开“要测量哪种行为？”。任务按模块分组，每行都注明测量方法：

| 模块                        | 方法                                                                       | 任务                                                                     |
|-----------------------------|----------------------------------------------------------------------------|--------------------------------------------------------------------------|
| **RodentPose**              | Core ML 姿态模型，6 个关键点（鼻尖、双耳、颈部、身体中心、尾根），逐帧识别 | 从社交到运动共 16 个范式——见[速查表](/zh/assays/pose#assays-pose) |
| **RodentLimb**              | Core ML 四肢模型，7 个关键点（四只爪、尾根、鼻尖、嘴）                     | 圆筒实验、悬尾实验、步态分析                                             |
| **RodentFlow**              | 经典质心追踪，10 Hz（背景差分，不使用神经网络）                            | 10 个视频范式——见[速查表](/zh/assays/pose#assays-flow)            |
| **悬尾实验 · 多格同步评分** | 格子检测、关键帧、逐格轮廓 / 像素运动                                      | 一段录像中的多只小鼠——见[多格悬尾实验](/zh/mac/tst)                    |

::: info

**同一个测试出现在两个模块里？**旷场、高架十字迷宫、明暗箱、新物体识别、Y 迷宫、T 迷宫、Barnes 迷宫和恐惧条件化在 RodentPose 和 RodentFlow 中都有。需要头朝向、基于鼻尖的物体 / 社交探索、探头或伸展评估姿势时选 **RodentPose**；需要经典的基于位置的指标、Morris 水迷宫或条件性位置偏好，或者姿态模型难以看清动物时选 **RodentFlow**。同一项研究请固定使用一个模块——两者的指标不能互换。

:::

**任务备注：**右键任务 → *添加／编辑备注…*（如“第 3 批，10 mg/kg”）。备注显示在任务名下方，并会导出。

**同名任务：**名称、实验类型和备注都相同（包括都没有备注）的任务会自动合并，所以重复新建“旷场”不会把数据拆散。需要两个独立的同名任务？右键 → *按不同备注新建同名任务…*。若合并会造成实验次数冲突或分组 / 性别矛盾，程序不会自动合并；合并前也会先备份工作区。

**删除任务：**右键 → *删除任务…*。会把该任务及其实验记录从项目中移除（如有分析在运行，请先暂停）。视频文件和已保存的追踪结果文件夹会保留，但此操作无法在 App 内撤销。

## 添加视频 {#mac-import}

选中一个任务（或其中的分组 / 小鼠——会自动预填该分组 / 小鼠），点 **+ 添加视频…**（<kbd>⌘</kbd><kbd>O</kbd>），或把视频拖到侧栏或中间列表。导入表格每行一个视频：

| 列          | 填写内容                                                                                   |
|-------------|--------------------------------------------------------------------------------------------|
| 小鼠编号 \* | 在任务内唯一，如 `M01`。由文件名预填。                                                     |
| 分组        | 可选（WT、KO、对照……）。该任务中已有实验的小鼠沿用原分组。                                 |
| 性别        | 可选，属于小鼠（RodentPose、RodentFlow 和 TST 任务显示）。                                 |
| 日期 \*     | 实验日期。由文件名预填，否则取文件创建日期（请核对！）。“全部使用第一行的日期”可一键统一。 |
| 实验次数 \* | 该小鼠在此任务中的第几次实验。自动填入下一个可用编号。                                     |
| 阶段        | 用于有固定阶段的任务（如新物体识别 训练 / 测试）。                                         |

有问题的行会标红（缺编号、实验次数已被占用、列表中同一小鼠的实验次数重复），修正前“导入”按钮不可用。拒绝重复是有意为之：重复记录会悄悄污染统计结果。

## 第 ① 步 实验信息 {#mac-info}

- **小鼠、分组、性别**——分组和性别应用于该小鼠在此任务中的所有实验；输入一个已有的小鼠编号，会把这次实验归入那只小鼠。
- **实验日期、实验次数**——必填。
- **阶段 / 天 / 当天试次**——范式需要时显示（如 Barnes 迷宫的学习天数和试次）。汇总时不同阶段不会合并。
- **备注**——剂量、处理、异常情况等（RodentPose 和 RodentLimb 任务显示；RodentFlow 可用任务备注记录批次信息）。
- **排除出组间汇总**——需填写原因（会导出）。被排除的实验保留自己的结果，但不进入小鼠均值、组统计和组间比较。排除标准请在看结果*之前*确定。

缺少小鼠编号、日期或实验次数的实验会显示橙色标记并出现在“缺信息”中，补全前不能分析。

## 第 ② 步 校准 {#mac-calibrate}

校准告诉 App：场地在哪里、实际多大（厘米）、物体或区域在哪，以及分析视频的哪一段。

1.  用时间滑块**选一帧标定画面**（场地边缘清晰、没有被手挡住）。
2.  若范式提供多种场地，**选择场地类型**（矩形、圆形、十字 / Y / T 迷宫，或仅导出姿态时的“不标定（像素）”）。
3.  **拖动手柄。**拖动时会显示 3 倍放大镜。需要精确时，点选手柄后用**方向键**微调（按住 <kbd>⇧</kbd> 移动更多）。
4.  **输入实际尺寸**（内部宽 / 高、直径、臂长 / 臂宽）。面板会显示比例（约 x 像素 / cm），可顺手核对是否合理。
5.  设置**范式参数**（区域大小、哪个是新物体、CS 开始时间……）和**分析时间段**（起点和时长；0 = 到结尾）。
6.  点**仅保存到本视频**（<kbd>⌘</kbd><kbd>S</kbd>）；之后的修改自动保存。**用于该任务的所有视频…**会把它复制到所有视频——仅在相机未移动时使用。

### 手柄颜色与标签

| 场地 / 标记          | 手柄                   | 放在哪里                                                                                         |
|----------------------|------------------------|--------------------------------------------------------------------------------------------------|
| 矩形                 | 黄色 `1–4`             | 场地底面内壁四角：左上、右上、右下、左下。坐标会做透视校正。                                     |
| 圆形                 | `C`、`R`               | C 对准圆心（拖动整体移动），R 拖到内壁。                                                         |
| 十字迷宫             | `C N E S W`            | C 在中央，N/E/S/W 在四个臂末端（N = 画面上方）。在参数中选择开放臂方向；青色为开放臂。           |
| Y 迷宫               | `J A B C`              | J 在三臂交汇处，A/B/C 在三个臂末端。                                                             |
| T 迷宫               | `J S L R`              | J 在选择点，S 在起始臂末端，L/R 在左右臂末端。                                                   |
| 三箱                 | 紫色 `L R`、青色 `L R` | 紫色 = 中箱左右两条分隔线（可分别拖动）；青色 = 两个铁丝杯中心。                                 |
| 物体（新物体识别）   | `A B`                  | 两个物体中心；设置物体半径和哪个是新物体。                                                       |
| Barnes 迷宫          | `T`                    | 目标（逃避）洞；其余洞按数量均匀排列。                                                           |
| 水迷宫（RodentFlow） | `P`                    | 平台中心。                                                                                       |
| Looming / 头朝向     | `S` / `Q`              | S 在巢穴中心；Q 在墙上的提示卡（可选的 0° 参考方向）。                                           |
| 圆筒（RodentLimb）   | 圆形或地面线           | 仰拍：与圆筒底面内缘重合（或“根据追踪自动拟合”）。侧拍：把虚线拖到地面（或“根据后爪位置估计”）。 |
| 步态 / 单鼠悬尾      | 标尺                   | 把两端拖到已知距离的标记上并输入该距离；不设比例时，距离以体长为单位。                           |

::: info

**RodentFlow 必须先标定再追踪**（其追踪器需要把小鼠位置映射到标定后的场地中）。RodentPose 和 RodentLimb 的追踪不依赖标定，可以之后再标定——结果会更新，无需重新识别。

:::

## 第 ③ 步 分析 {#mac-analyse}

- 点**分析该视频**（<kbd>⌘</kbd><kbd>R</kbd>）。若已有视频在运行，按钮会变成“加入队列”。视频按顺序逐个分析。
- 页面显示进度、视频时间、**预计剩余时间**以及实时追踪预览（约每秒更新一次）。
- **暂停**会保留已完成的部分；**继续分析**从停下处继续——即使退出过 App 也可以。长视频会分段写入磁盘，内存占用可控。
- 同一页面的“该任务的全部动物”卡片 → **分析其余视频（n 个）**会把所有准备就绪的视频加入队列；“全部暂停”可停止队列。缺信息或（RodentFlow）未标定的视频会被列出并跳过。
- **重新分析…**会保留之前的结果，复核将使用新结果（之后请重新复核追踪）。

## 第 ④ 步 复核与导出 {#mac-review}

### “结果”页

显示该次实验按原版算法得到的指标与图表，突出主要指标，并标明当前的分析时间段和阶段。时间段、区域或参数请在“校准”中修改——结果会重新计算，无需重新追踪。**导出结果与图表…**会把这次实验的指标、方法说明以及（可选）PNG 图表写入一个新文件夹。

### 逐帧复核与导出：追踪复核

不需要看完整段视频。一次简短而有条理的检查就能发现大多数问题：

1.  选择**复核范围**（默认第 0–99 帧）或快捷选项：*开头、中间、结尾、随机*。
2.  按**播放**（<kbd>⌥</kbd><kbd>P</kbd>），速度可选“逐帧播放”、0.25×、0.5×、1×、2×；或用 <kbd>⌥</kbd><kbd>←</kbd> / <kbd>⌥</kbd><kbd>→</kbd> 逐帧查看。橙色线为之前 2 秒的轨迹。
3.  遇到关键点明显错误的帧，按 <kbd>⌥</kbd><kbd>F</kbd>（*此处追踪错误*）。
4.  记录**结论**（未复核 / 追踪无误 / 追踪有问题）和备注，它们随该次实验保存并导出。
5.  点**下一次待复核的实验 →**（或右上角的“下一次实验 →”）。

结论为“追踪有问题”的实验*不会*被自动排除——由你按预先设定的标准决定。若解码画面与追踪时间戳对不上，App 会隐藏标点，而不是画在错误的位置。

### 追踪事件、图表与原始文件（RodentPose / RodentLimb）

- **追踪质控事件**把连续的“识别失败”“未检测到小鼠”“置信度低”帧合并显示。这些是质量标记，不是行为；追踪质量好的视频可以没有任何事件。点击事件可跳转；可标为“接受”或“标记问题”。
- 选择**作图帧范围**（含首尾，从 0 开始），勾选要导出的内容：原始关键点 CSV、质控筛选后的 CSV、逐帧 / 分段质控 CSV、溯源 JSON、轨迹图和置信度图 PNG、标注截图，以及（RodentLimb）事件时间线。点**导出所选文件和图表…**（<kbd>⌘</kbd><kbd>E</kbd>）。图表由已保存的追踪数据生成，这里不会重新运行模型。
- **标注 MP4** 为可选项：App 会先测速估时，确认后再导出，不会重复运行模型。
- RodentFlow 实验在同一页面导出 10 Hz 质心采样点（CSV）和追踪复核记录（JSON）。

## 任务页、分组页、小鼠页 {#mac-overviews}

- **任务页：**全部实验的表格（小鼠、分组、日期、实验次数、阶段、分析状态、主要指标、追踪复核、是否纳入）。双击打开；多选后右键可用同一原因批量排除 / 重新纳入。标签页：*全部实验*、*组间比较*、*导出*。
- **分组页：**该组的小鼠、各阶段描述统计（每只小鼠先取均值，n = 小鼠数）、组级导出，以及*重命名分组*（应用于此任务中该组的所有小鼠）。
- **小鼠页：**该小鼠的各次实验、某一指标随实验次数的变化（已排除的实验为灰色），以及重命名 / 修改分组 / 性别。改成已有编号时，只有在实验次数不冲突时才会合并。

打开这些页面时，缺少或过期的实验结果会在后台按顺序计算（进度显示在页面顶部，可“停止”）。结果随每次追踪保存；它所依赖的任何内容改变时会自动重算。

## 智能列表与工具 {#mac-tools}

**全部实验**（<kbd>⌘</kbd><kbd>2</kbd>）是项目中所有实验的一张总表，含标定、分析和追踪复核状态——适合最后做一次完整性检查。右键可“在所属任务中打开”或“从项目中移除”（文件本身不会被删除）。

**工具**（<kbd>⌘</kbd><kbd>3</kbd>）用于检查和排错，不用于正式实验：*模型*（查看已打包的模型）、*手动追踪*、*长视频追踪*（到你选择的文件夹）、*复核手动结果*、*RodentLimb 轨迹分析*、*任务目录*，以及*旧项目查看器*（只读打开旧的 `.rodentproj` 文件，不做修改）。在工具中得到的结果不关联任务或小鼠。
