# 键盘快捷键（Mac）

| 快捷键                                                                         | 功能                        | 适用位置             |
|--------------------------------------------------------------------------------|-----------------------------|----------------------|
| <kbd>⇧</kbd><kbd>⌘</kbd><kbd>N</kbd>                                           | 新建任务…                   | 任意位置             |
| <kbd>⌘</kbd><kbd>O</kbd>                                                       | 添加视频… / 添加 TST 录像…  | 已选中任务时         |
| <kbd>⌘</kbd><kbd>1</kbd> · <kbd>⌘</kbd><kbd>2</kbd> · <kbd>⌘</kbd><kbd>3</kbd> | 任务 · 全部实验 · 工具      | 任意位置             |
| <kbd>⌘</kbd><kbd>+</kbd> / <kbd>⌘</kbd><kbd>−</kbd>                            | 放大 / 缩小字体             | 任意位置             |
| <kbd>⌘</kbd><kbd>,</kbd>                                                       | 设置（语言、字体大小）      | 任意位置             |
| <kbd>⌘</kbd><kbd>[</kbd> / <kbd>⌘</kbd><kbd>]</kbd>                            | 上一步 / 下一步             | 实验步骤             |
| <kbd>⌘</kbd><kbd>S</kbd>                                                       | 仅保存到本视频（标定）      | 校准                 |
| 方向键（<kbd>⇧</kbd> 移动更多）                                                | 微调选中的手柄              | 校准                 |
| <kbd>⌘</kbd><kbd>R</kbd>                                                       | 分析该视频 / 继续分析       | 分析                 |
| <kbd>⌥</kbd><kbd>P</kbd>                                                       | 播放 / 暂停                 | 逐帧复核             |
| <kbd>⌥</kbd><kbd>←</kbd> / <kbd>⌥</kbd><kbd>→</kbd>                            | 上一帧 / 下一帧（或采样点） | 逐帧复核             |
| <kbd>⌥</kbd><kbd>F</kbd>                                                       | 标记“此处追踪错误”          | 逐帧复核             |
| <kbd>⌘</kbd><kbd>E</kbd>                                                       | 导出所选文件和图表          | 逐帧复核与导出       |
| <kbd>Return</kbd> / <kbd>Esc</kbd>                                             | 下一步 / 取消               | TST 录像窗口、对话框 |
