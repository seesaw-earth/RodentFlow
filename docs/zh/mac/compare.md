# 组间比较与统计（Mac）

打开任务，选择**组间比较**。依次选择*设计*、*指标*、*阶段*、纳入哪些实验（*全部实验（按小鼠取平均）*或*仅第 n 次*）、*统计*（参数检验 / 非参数检验）和*比较方式*（两两比较 / 与第一组比较）。

| 设计       | 每只小鼠的值                                               | 检验（两组 · ≥ 3 组）                                                                                                           |
|------------|------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------|
| 组间比较   | 其纳入实验的均值                                           | Welch t（附 95% CI）或 Mann–Whitney U · 单因素方差分析 + Tukey–Kramer，或各组与第一组比较 + Holm；Kruskal–Wallis + Dunn（Holm） |
| 按实验次数 | 每个实验次数一个值                                         | 两因素混合方差分析（组 × 实验次数，Greenhouse–Geisser 校正）+ 各次组间检验（Holm 校正）                                         |
| 按天       | 同一天的试次先平均（学习曲线）                             | 同上                                                                                                                            |
| 时间进程   | 一次实验内的序列（时间段、CS 呈现、TST 每分钟）            | 同上                                                                                                                            |
| 配对指标   | 同一小鼠的两个指标（新物体 vs 熟悉物体、开放臂 vs 闭合臂） | 组内：配对 t / Wilcoxon；组间：交互作用或差值检验                                                                               |
| 阶段间变化 | 每只小鼠 阶段 B − 阶段 A（如 测试 − 前测）                 | 同“组间比较”                                                                                                                    |

- **对照组排第一：**名称像对照的组（WT、Control、Vehicle、Saline、Sham）默认排在最前；可在列表中调整顺序、颜色和是否纳入，设置按任务保存。
- **参考值：**对有天然“无偏好值”的指标（DI = 0、识别指数 = 50%、目标象限 = 25%），可勾选*各组与参考值比较*。
- **选项：***显示每只小鼠*；*包含已排除的实验*（仅用于敏感性查看）。
- **导出该比较…**会生成图（PNG）、方法与结果摘要（TXT）、完整结果（JSON）和每只小鼠进入检验的数值（CSV）。

::: warning

**这些是用于初步查看数据的统计**：没有对多个指标、多种设计或多次查看数据做校正。每组少于 2 只时不给检验结果（并说明原因）。报告前请用预先设定的分析确认——导出的 `animals.csv` 和 `comparison_animal_values.csv` 可直接用于 R、Python 或 [GraphPad Prism](https://www.graphpad.com/)。

:::
