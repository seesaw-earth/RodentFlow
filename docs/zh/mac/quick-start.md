# Mac 快速上手（10 步）

1.  **打开 RodentFlow。**切换中文 / English：工具栏的地球图标“语言”菜单，或 **RodentFlow › 设置…**（<kbd>⌘</kbd><kbd>,</kbd>）。
2.  **新建任务：**点**新建任务…**（<kbd>⇧</kbd><kbd>⌘</kbd><kbd>N</kbd>），在“要测量哪种行为？”中选择测试（可搜索）。项目会自动创建。
3.  **添加视频：**点 **+ 添加视频…**（<kbd>⌘</kbd><kbd>O</kbd>），或直接把文件拖到侧栏 / 中间列表。
4.  **核对导入表格：**小鼠编号、日期、实验次数必填；分组、性别可选。用“新小鼠的分组 → 应用”可一次填满一列。点**导入**。
5.  **在中间列表打开一次实验**，按顶部四步进行：**① 实验信息 → ② 校准 → ③ 分析 → ④ 复核与导出**（<kbd>⌘</kbd><kbd>[</kbd> / <kbd>⌘</kbd><kbd>]</kbd> 切换上一步 / 下一步）。
6.  **校准：**把彩色手柄拖到场地上（拖动时会出现放大镜），输入场地实际尺寸（cm），设置分析时间段，然后点**仅保存到本视频**（<kbd>⌘</kbd><kbd>S</kbd>）。若相机没动过，可选**用于该任务的所有视频…**
7.  **分析：**点**分析该视频**（<kbd>⌘</kbd><kbd>R</kbd>）。其他视频会排入队列；运行期间可继续标定或复核其他动物，也可随时**暂停** / **继续分析**。
8.  **复核追踪：**在“复核与导出 → 逐帧复核与导出”中播放第 0–99 帧（<kbd>⌥</kbd><kbd>P</kbd>），标记错误帧（<kbd>⌥</kbd><kbd>F</kbd>），记录结论“追踪无误”或“追踪有问题”。然后点**下一次待复核的实验 →**。
9.  **查看数值：**“结果”页显示该范式的指标和图表。点侧栏中的任务，可看到全部实验和**组间比较**。
10. **导出：**在任务页点**导出任务数据…**，会生成一个包含英文 CSV 和 `README_methods.txt` 的文件夹，可直接用于 R、Python、Prism 或 Excel。

::: tip

**小贴士：**同一批的第一只小鼠请认真标定和复核。同一任务的新视频会沿用上一个视频的标定（会显示“标定沿用自 ……，请检查”），之后的动物通常只需快速确认。

:::
