# RodentFlow Mac 版

::: info
本页根据 Mac 版 RodentFlow 0.7.1 和 iPhone、iPad 版 RodentFlow 1.0（姿态版，原名 RodentStudio）编写。
:::

Mac 版面向完整的研究：多只动物、分组、重复测试、统计和批量导出。它运行姿态模型（RodentPose 与 RodentLimb）、经典质心追踪和多格悬尾实验。先看[Mac 快速上手](./quick-start.md)，其余页面按需查阅。在 Mac 和 iPhone、iPad 之间怎么选，见[我该用哪个版本？](../guide/editions.md)

## 理解这五点，用起来更顺手 {#concepts}

- **1. 一段视频 = 一只小鼠的一次实验。** 每段视频只属于一只小鼠，并有**实验日期**和**实验次数**（1、2、3……即该小鼠在此任务中的第几次）。在 Mac 版中，这三项是分析前的必填项。
- **2. 层级本身就是数据。** **项目 → 任务 → 分组 → 小鼠 → 实验。**“任务”是一个行为学测试（如“旷场—第 3 批”）。分组（WT、KO、对照……）可选，并且*属于小鼠*：修改某只小鼠的分组或性别，会同时应用到它在该任务中的所有实验。
- **3. 任务决定方法。** 你不需要选模型。选定任务，就决定了标定方式、分析方法和模型（6 关键点姿态、7 关键点四肢姿态、经典质心追踪或多格轮廓评分）。
- **4. 追踪一次，评分多次。** 追踪（最耗时的部分）只做一次。区域、阈值和分析时间段在追踪之后才应用，修改后结果**无需重新追踪**即可更新。原始视频只读不改。
- **5. n = 小鼠数。** 汇总和统计时，同一阶段内一只小鼠纳入的多次实验先取平均，因此 **n 是小鼠数**——不是实验数，更不是帧数。不同阶段（如训练与测试）不会合并，除非你明确选择。
