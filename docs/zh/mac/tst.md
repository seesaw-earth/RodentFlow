# 多格悬尾实验（TST）

该流程用于对**同一段录像中并排悬挂的多只小鼠**评分：自动找到格子，找到所有小鼠都已挂好的时刻（*关键帧*），逐格测量运动，然后把每个格子保存为一只小鼠的一次普通实验——因此分组、组间比较和导出与其他任务完全一样。（若每段视频只有一只小鼠，并需要爪部关键点、抱握和爬尾判定，请改用 RodentLimb 的“悬尾实验”任务。）

## 操作步骤

1.  **新建任务**“悬尾实验 · 多格同步评分”，点**添加 TST 录像…**（<kbd>⌘</kbd><kbd>O</kbd>）或把视频拖到侧栏。录像需逐段分析。分析窗口顶部有步骤条——**视频 › 格子 › 关键帧 › 结果与小鼠**；左边看画面，右边调设置，底部固定“上一步 / 取消（<kbd>Esc</kbd>）/ 下一步（<kbd>Return</kbd>）”。
2.  **格子：**程序会自动检测格子（检测不到时先平均分成 6 格）。设置“格子数”，把白色手柄拖到格子之间的隔板上，点击格子可选中或跳过。检测到小鼠的格子已预先勾选。然后点**寻找关键帧 →**（视频已剪辑为所有小鼠挂好之后才开始时，可用“手动设定起点…”）。
3.  **关键帧：**所有选中格子都已有小鼠并持续设定时长的第一个时刻。找到后即可点“采用此关键帧 →”，但让扫描完整跑完，各格的运动框才能覆盖小鼠的全部活动范围，并能看出小鼠何时被取下。可用 ±0.25 秒 / ±1 秒按钮或点击时间轴微调。拖动黄色手柄，使*分析带*覆盖每只小鼠并在上方留一点空间。然后点**开始分析 →**。
4.  **结果与小鼠：**一格一行，同时显示不动时间和小鼠信息。实验日期整段录像只填一次；逐格填写小鼠编号、分组、性别、实验次数；空格或不可用的格子取消勾选（不会生成实验记录）。只有真正的冲突才会标红。点**保存 N 次实验**。
5.  小鼠会出现在侧栏，并自动打开第一只的“复核与导出”：打开原始录像检查该格，选择“评分无误”或“存在问题”（选中即保存），必要时填写原因并排除。

## 评分原理

- **每只小鼠从自己挂上的时刻开始计时。**标准测试时长 6 分钟。**主要指标（★）是第 2–6 分钟的不动时间**；同时报告第 0–2、0–6 分钟和全程，以及首次不动潜伏期、不动次数 / 平均 / 最长片段、每分钟不动时间和*运动强度*（活动时的平均运动量，即挣扎的剧烈程度）。
- 默认指标是每只小鼠固定**运动框内的像素变化**，比较前先对齐画面以抵消被动摆动（摆动不计为运动）。另有两种基于轮廓的指标可供对照。
- 默认从关键帧分析到视频结束；需要固定时长时打开“到此为止（限定时长）”。没有小鼠的帧（已取下、爬尾、出画）计为“无小鼠”，不计为不动；不动百分比的分母只包含有小鼠的帧。
- “无小鼠”帧超过 10% 的格子会提示复核。若某只鼠挂上后没录满 6 分钟，也会给出提示。

::: warning

**请针对自己的装置校准阈值。**TST 自动评分尚未经过盲法人工评分验证，默认阈值（鼠体的 2%）只是起始值。先人工评分 2–3 段不动程度不同的视频（例如使用 [BORIS](https://www.boris.unito.it/)），然后在“结果与小鼠”中点**用人工评分校准阈值…**：填入人工评分的秒数（第 2–6 分钟），点“寻找最佳阈值”并应用。整个研究使用同一阈值。

:::

## 之后修改设置

打开任意一次 TST 实验，点**调整参数并重新分析…**（右键菜单中也有）。录像会以原来的格子、起点和参数重新打开。阈值、最短不动片段和时间窗可立即修改；改格子、分析带或起点则需重新分析。**更新实验**会原地更新已有实验（实验 ID 不变；因数值改变，复核结论会清空，备注保留），为新勾选的格子新建实验，并删除不再保存的格子对应的实验（删除前会提示数量）。

## 如何解读 TST 结果

不动时间更准确的说法是**被动应对策略**，不宜直接称为“抑郁样”行为。镇静或兴奋、运动能力、体重、性别、品系和尾部不适都会影响结果，建议配合运动能力对照（如同一批小鼠的旷场总距离）一起解读。参见 [Can 等 2012](https://doi.org/10.3791/3769) 和 [Commons 等 2017](https://doi.org/10.1021/acschemneuro.7b00042)。
