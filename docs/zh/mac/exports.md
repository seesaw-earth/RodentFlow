# 导出文件说明（Mac）

无论界面语言是什么，所有导出都使用**英文列名和标识**，并保留你的原始编号。你自己输入的内容（小鼠编号、分组名、备注、排除原因）按原样导出——如需全英文数据集，请在输入时使用英文。每次导出都会在你选择的文件夹中**新建一个文件夹**，不会覆盖旧文件。

## 任务级与组级导出

任务页 → *导出* → **导出任务数据…**，或分组页 → **导出组数据…**

| 文件                  | 内容                                                                                                                                                   | 用途                       |
|-----------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------|
| `sessions.csv`        | 每次实验一行：任务、小鼠、分组、性别、日期、实验次数、阶段 / 天 / 试次、是否排除及原因、状态、追踪复核、质控警告、分析时间段、主要指标、视频文件、备注 | 核对与追溯到原视频         |
| `metrics_long.csv`    | 每次实验 × 每个指标一行（键、英文名、单位、数值、是否主要指标）                                                                                        | R / pandas 的整洁数据      |
| `metrics_wide.csv`    | 每次实验一行，每个指标一列                                                                                                                             | Excel、快速作图            |
| `animals.csv`         | 每只小鼠 × 每个阶段：纳入实验的均值、纳入数量、实验次数和日期                                                                                          | **统计分析（n = 小鼠数）** |
| `group_summary.csv`   | 每个阶段 × 分组 × 指标：n、均值、SD、SEM、中位数、四分位数、最小值、最大值                                                                             | 论文表格                   |
| `timecourse_long.csv` | 每次实验 × 每个时间段（如 TST 每分钟）                                                                                                                 | 重复测量 / 混合模型        |
| `README_methods.txt`  | 数值如何得到、计数、被排除的实验及原因、警告                                                                                                           | 方法部分、给审稿人看       |

## 逐帧追踪数据（DeepLabCut 格式）

任务页或分组页 → **导出逐帧数据…**（在后台进行；每次实验每分钟视频约 1 MB）。

- **RodentPose / RodentLimb：**`frames/<小鼠>_<日期>_S<次数>_DLC.csv` 为 DeepLabCut 格式（三行表头：scorer / bodyparts / coords；每个关键点 x、y、likelihood），另有 `…_frames.csv`，含视频时间、帧号、是否在分析时间段内、检测置信度、是否推理失败。
- **RodentFlow：**`…_centroid.csv`（画面与场地坐标，单位为像素、归一化值和厘米；置信度、是否插值、所在区域、运动指数），一份只含 centroid 一个点的 DLC 文件，有迷宫事件时另有 `…_maze_events.csv`。
- `frames_index.csv` 和 `frames_metadata.json` 列出每次实验、模型、关键点名称、帧数、分析时间段及读取错误。
- 约定：校正旋转后的竖直画面像素，原点在左上角，x 向右，y 向下（与 DLC 相同）。缺失的关键点 x、y 为空、likelihood 为 0。`inference_failed = 1` 表示模型没能运行——与“画面中没有动物”不是一回事。

## 多格 TST 文件

会自动包含在任务 / 组级导出中，也可点**仅导出 TST 数据（JSON + CSV）…**单独导出。

| 文件                                                          | 内容                                                                                                         |
|---------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------|
| `tst_animals.csv`                                             | 每只小鼠：其纳入实验的均值——**统计分析用这一份**                                                             |
| `tst_sessions.csv`                                            | 每次实验：身份、时间（挂上时刻、关键帧、时间窗、录制比例）、全部指标、质控与方法参数                         |
| `tst_minutes_long.csv`                                        | 每次实验 × 挂上后每分钟一行，含是否录完整                                                                    |
| `tst_bouts.csv`                                               | 每个不动片段（开始、结束、时长；从挂上时起及视频中的时间）                                                   |
| `tst_frames_long.csv`、`tst_motion_1s.csv`、`tst_frames.json` | 逐帧运动信号本身（评分用值、原始值、阈值、是否不动、是否无小鼠）——可用任何标准重新判定，或与人工逐帧评分对比 |
| `tst_export.json`、`tst_data_dictionary.csv`                  | 以上全部内容的结构化文件，以及每一列的含义和单位                                                             |

若同一任务中的录像使用了不同的指标或阈值，JSON 的说明中会警告：这些数值不能直接比较。

::: tip

**用 Excel 打开 CSV：**文件为 UTF-8 编码。若你自己输入的中文备注显示为乱码，请通过“数据 › 从文本/CSV”导入并选择 UTF-8（Numbers 可直接打开）。指标名使用普通 ASCII 连字符（如 `min 2-6`），列名不会出现这个问题。

:::
