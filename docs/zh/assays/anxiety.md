# 焦虑与情绪

旷场、高架十字迷宫和明暗箱可以用视频打分；埋珠实验和糖水偏好需要手动录入或导入。

## 旷场 / 中央区 {#open-field-center}

测量自发活动，以及对新环境中开阔中央区的回避。

**场地**：矩形（四个角）或圆形（圆心和边缘）。填写底面内侧尺寸。

**设置**

| 设置 | 默认值 | 含义 |
|---|---|---|
| 中央区大小 | 50 % | 同心中央正方形的边长占场地边长的比例。边长 50 % 即面积 25 %。圆形场地为中央圆半径占场地半径的比例。 |
| 运动阈值 | 2 cm/s | 速度达到或超过此值即计为运动 |
| 最短不动时长 | 2 s | 低于运动阈值、持续至少这么久才计为不动 |
| 时间段 | 5 min | 分段序列的时长（1、2、5 或 10 min） |
| 进入区域标准 | 0.3 s | 在中央区停留多久才算一次进入 |

**指标**

| 指标 | 单位 | 定义 |
|---|---|---|
| 总距离 | m | 相邻两个检测到的样本之间步长的总和 |
| 平均速度 | cm/s | 总距离 / 分析时长 |
| 运动时间 | % | 速度 ≥ 运动阈值的时间 / 速度可计算的时间 |
| 不动时间 | s | 低于运动阈值、且持续至少最短时长的各段时间之和 |
| 中央区时间 | s、% | 在中央区内的时间；% 以检测到动物的时间为分母 |
| 进入中央区次数 | 次 | 满足进入标准的“外周 → 中央”转换次数 |
| 进入中央区潜伏期 | s | 第一次进入中央区的时间（从未进入则为分析长度） |
| 中央区距离 | % | 在中央区内移动的距离 / 总距离 |
| 追踪成功样本 | % | 检测到动物的样本 / 全部样本 |

序列：每个时间段的距离、每个时间段的中央区时间。

**建议**：分析固定长度，例如前 10 分钟，保证各动物在相同时间内比较。速度用相隔 0.2 s 的两个位置计算（中心差分），所以几毫米的追踪抖动在默认阈值下不会被算作运动。

## 高架十字迷宫 {#elevated-plus-maze}

比较开放臂与闭合臂上的停留时间。

**场地**：十字迷宫，**C** 放在中心，**N/E/S/W** 放在各臂末端。填写 **臂长（不含中央区）** 和 **臂宽**。N 是画面上方。

**设置**

| 设置 | 默认值 | 含义 |
|---|---|---|
| 开放臂 | 北–南（上/下） | 哪一对是开放臂，另一对为闭合臂 |
| 中央区外扩 | 0 cm | 将中央方块每边向外扩大。默认中央区就是两臂交叉处的方块，边长等于臂宽。 |
| 进入区域标准 | 0.25 s | 在臂内停留多久才算一次进臂 |

**指标**

| 指标 | 单位 | 定义 |
|---|---|---|
| 开放臂时间 | % | 开放臂时间 / （开放臂 + 闭合臂时间）× 100，分母不含中央区时间 |
| 开放臂进入次数 | % | 开放臂进入 / （开放臂 + 闭合臂进入）× 100 |
| 开放臂时间、闭合臂时间、中央区时间 | s | 两条开放臂、两条闭合臂、中央方块内的时间 |
| 开放臂进入次数、闭合臂进入次数 | 次 | 满足进入标准的进臂次数 |
| 总进臂次数 | 次 | 开放臂 + 闭合臂进入次数，可作为活动量指标 |
| 进入开放臂潜伏期 | s | 第一次进入开放臂的时间 |
| 总距离 | m | 步长总和（见下面的注意事项） |
| 追踪成功样本 | % | |

标签：进臂序列，例如 `ON CE CW OS`，其中 O/C 表示开放/闭合，N/E/S/W 表示哪条臂。

**如何判断在哪条臂上**：每个位置先根据校准的中线映射到最近的一条臂上（见[迷宫几何](../principles/metrics.md#maze-geometry)），再按相对中心的方向确定臂，中央区由中央方块确定。

::: warning 十字迷宫的总距离
在我们的验证视频中，十字迷宫只占画面宽度的一半左右（分析分辨率下约 1.5 像素/cm）。时间和进臂次数与真实值完全一致，但总距离偏高 35 %，因为小鼠原地嗅探时的姿态变化会累积成距离。十字迷宫的距离只适合在相同拍摄条件下做组间比较；或者把迷宫拍得更满画面。见[验证](../principles/validation.md)。
:::

## 明暗箱 {#light-dark-box}

比较明亮开放的箱室与黑暗封闭箱室中的停留时间。

**场地**：矩形覆盖整个箱体；如果暗箱有盖、看不见，也可以只覆盖明箱。

**设置**

| 设置 | 默认值 | 含义 |
|---|---|---|
| 明箱 | 左 | 明箱在画面中的哪一侧 |
| 明箱长度 | 67 % | 校准长度中属于明箱的比例。如果只校准了明箱，用 100 %。 |
| 看不到小鼠时计为在暗箱 | 开 | 看不到动物的样本计入暗箱时间（暗箱有盖时） |
| 进入区域标准 | 0.5 s | 在一个箱室停留多久才算一次穿箱 |

**指标**

| 指标 | 单位 | 定义 |
|---|---|---|
| 明箱时间 | %、s | 明箱时间 / （明箱 + 暗箱时间）× 100 |
| 暗箱时间 | s | 在暗箱中的时间，开启时包括看不到动物的样本 |
| 穿箱次数 | 次 | 满足进入标准的箱室转换次数 |
| 进入暗箱潜伏期 | s | 第一次进入暗箱的时间（一开始就在暗箱则为 0） |
| 明箱内距离 | m | 在明箱内移动的距离 |
| 可见样本 | % | 能看到动物的样本比例。暗箱有盖时它约等于明箱时间比例，不会产生质量提示。 |

**建议**：暗箱有盖时保持默认的 0.5 s 进入标准，这样明箱里短暂的检测丢失不会被误判为进入暗箱。

## 埋珠实验 {#marble-burying}

手动录入：测试结束时，统计被垫料覆盖至少三分之二的玻璃珠数量。

| 字段 | 默认值 |
|---|---|
| 笼内玻璃珠数 | 20 |
| 被掩埋数（≥ 2/3 覆盖） | 必填 |
| 部分掩埋数 | 可选 |
| 测试时长 | 30 min |

| 指标 | 单位 | 定义 |
|---|---|---|
| 掩埋玻璃珠 | %、颗 | 被掩埋数 / 总数 × 100 |
| 部分掩埋 | 颗 | 按录入值 |

## 糖水偏好 {#sucrose-preference}

手动录入，或以原始瓶重导入，每个测量日一行。

| 字段 | 说明 |
|---|---|
| 体重 | g，可选；用于计算每公斤摄入量 |
| 糖水浓度 | %，默认 1 |
| 每天：糖水瓶起始 / 结束重量、清水瓶起始 / 结束重量 | g（≈ mL） |
| 每天：糖水漏液对照、清水漏液对照 | 放在空笼上的瓶子减少的重量，从摄入量中扣除 |
| 每天：测量时长 | h，默认 24 |

| 指标 | 单位 | 定义 |
|---|---|---|
| 糖水偏好 | % | Σ 糖水 / （Σ 糖水 + Σ 清水）× 100，多天合并；机会水平为 50 % |
| 日均偏好 | % | 每天偏好值的平均 |
| 糖水、清水、总摄入量 | g/day | 摄入量 = 起始 − 结束 − 漏液，再除以测量天数 |
| 糖水摄入量 / 体重 | g/kg/day | 按体重校正的糖水摄入量 |

序列：每天的偏好。摄入量为负（提示称重错误）或每日总摄入量低于 1 g（提示漏液）时，App 会给出提示。

**建议**：每天交换两个瓶子的位置，以排除侧别偏好。合并偏好按摄入量给各天加权，日均偏好则每天权重相同。
