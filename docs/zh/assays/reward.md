# 奖赏与决策

## 条件性位置偏好 {#conditioned-place-preference}

测试动物对与药物或奖赏配对过的箱室的偏好。

**场地**：矩形覆盖整个装置，各箱室在画面中从左到右并排。阶段选 **前测**、**条件化** 或 **测试**。

**设置**

| 设置 | 默认值 | 含义 |
|---|---|---|
| 装置 | 两箱 | 两箱或三箱 |
| 分隔线位置（两箱） | 距左侧 50 % | 两个箱室的分界处 |
| 中间箱宽度（三箱） | 场地的 20 % | 居中的中间箱宽度 |
| 配对（药物 / 奖赏）侧 | 左 | 哪一侧的箱室是配对箱 |
| 进入区域标准 | 0.5 s | 一次进入箱室的最短停留时间 |

| 指标 | 单位 | 定义 |
|---|---|---|
| 偏好分数 | s | 配对侧箱时间 − 非配对侧箱时间 |
| 配对侧偏好 | % | 配对 / （配对 + 非配对）× 100；机会水平为 50 % |
| 配对侧箱时间、非配对侧箱时间 | s | 在两侧箱室中的时间 |
| 中间箱时间 | s | 在中间箱的时间（三箱装置） |
| 配对箱进入次数 | 次 | 进入配对箱的次数 |
| 总距离 | m | |

**分析**：CPP 通常看的是从前测到测试的变化。在组间分析中选 *阶段间变化*，**从** 前测 **到** 测试，测量指标选 *偏好分数*，比较各组每只动物的“测试 − 前测”差值。*配对测量*（配对侧 vs 非配对侧）则检验每组内部的偏好。

## 双臂老虎机任务 {#two-armed-bandit}

动物在两个奖励概率不同的选项之间逐试次选择，通常更好的选项会发生反转。数据来自操作箱或 T 迷宫，可以逐试次录入（**录入试次**），更方便的做法是从逐试次 CSV 导入。

**列**（每个试次一行）：`subject`、`group`、可选的 `day` 或 `phase`（场次 / 区组）、`trial`、`choice`（`L`/`R`、`left`/`right` 或 `0`/`1`）、`reward`（`0`/`1`），以及可选的 `p_left`、`p_right`（该试次的奖励概率）和 `rt`（反应时，秒）。见[示例文件](/samples/example_bandit_trials.csv)。

| 指标 | 单位 | 定义 |
|---|---|---|
| 高价值选择 | % | 选择奖励概率较高选项的比例（需要 `p_left`/`p_right`）；机会水平为 50 % |
| 获奖率 | % | 获得奖励的试次 / 试次数 × 100 |
| 赢-留 | % | P（上一试次获奖时，本次做相同选择）× 100 |
| 输-换 | % | P（上一试次未获奖时，本次换选择）× 100 |
| 切换率 | % | P（本次选择与上一次不同）× 100 |
| 选择右侧 | % | 侧别偏好；机会水平为 50 % |
| 学习率 α | — | Q-learning 拟合（见下文） |
| 逆温度 β | — | Q-learning 拟合 |
| 模型伪 R² | — | 1 − NLL / (n · ln 2)，0 表示预测能力等于随机 |
| 试次数 | 次 | |
| 平均反应时 | s | `rt` 列的平均值 |

序列：提供奖励概率时，给出每次反转前 5 个试次到反转后 20 个试次选择新的最优选项的概率。结果页还会画出整个场次的选择。

**Q-learning 模型**：每个选项有一个价值 *Q*，初始为 0.5。每个试次后，更新所选选项的价值：

*Q* ← *Q* + α (*r* − *Q*)，获奖时 *r* = 1，否则为 0。

选择概率由两个价值之差经 softmax 给出：

P(右) = 1 / (1 + exp(−β (*Q*<sub>右</sub> − *Q*<sub>左</sub>)))。

α（0–1）和 β（0–50）用每只动物的完整试次序列，以最大似然拟合：先网格搜索，再局部搜索细化。至少需要 10 个试次。负对数似然和 BIC 列在结果的参数中。
