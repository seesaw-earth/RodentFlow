# 运动功能

平衡木和步态分析由实验人员现场或从视频中打分，再手动录入或导入。RodentFlow 负责平均、派生指标和组间统计。

## 平衡木 {#beam-walking}

测试动物通过窄木条时的平衡与协调能力。

**字段**：**平衡木**（木条的标签，如 `12 mm`、`6 mm 圆杆`），可选 **木条宽度**（mm）。然后每个试次一行：

| 每个试次 | 说明 |
|---|---|
| 通过时间 | s，必填 |
| 失足次数 | 次，默认 0 |
| 跌落 | 是 / 否 |

训练天数用 **天** 区分，不同木条用 **平衡木** 区分。组间分析可以按木条筛选。

| 指标 | 单位 | 定义 |
|---|---|---|
| 通过时间 | s | 各试次通过时间的平均值 |
| 每试次失足次数 | — | 每个试次失足次数的平均值 |
| 总失足次数 | 次 | 各试次之和 |
| 跌落 | % | 发生跌落的试次 / 试次数 × 100 |
| 试次数 | 次 | 录入的试次数 |

序列：每个试次的通过时间。

**导入**：每个试次一行，列为 `subject, group, phase, day, trial, time_s, slips, fell`，其中 `phase` 是木条。[示例文件](/samples/example_beam_trials.csv)就是这种格式。在组间分析中选 *跨天比较*，可以得到每种木条的学习曲线和混合方差分析。

## 步态分析 {#gait-analysis}

足印法（墨水或颜料）步态分析。

**字段**：可选 **跑道时长**（s）和 **跑道距离**（cm），用于计算步频和速度。然后每一步一行：

| 每一步 | 说明 |
|---|---|
| 侧别 | —、左或右 |
| 后肢步长 | cm |
| 前肢步长 | cm |
| 后肢步宽 | cm |
| 前肢步宽 | cm |
| 前后爪重叠距离 | cm，同侧前爪与后爪印之间的距离 |

测量跑道中段连续的几步，跳过加速和停下时的第一步和最后一步。

| 指标 | 单位 | 定义 |
|---|---|---|
| 后肢步长、前肢步长 | cm | 各步平均 |
| 后肢步宽、前肢步宽 | cm | 各步平均 |
| 前后爪重叠距离 | cm | 前后爪印距离的平均值 |
| 后肢步长变异系数 | % | 后肢步长的 SD / 均值 × 100（变异性；至少需要 2 步） |
| 后肢步长不对称性 | % | \|左 − 右\| / 左右均值 × 100（需要两侧都有数据） |
| 步频 | 步/s | 录入的步数 / 跑道时长 |
| 行走速度 | cm/s | 跑道距离 / 跑道时长 |
