# 学习与记忆

本页的六种范式都可以用视频打分，也可以手动录入或导入。

## Y 迷宫 {#y-maze}

自发交替：动物倾向于进入最近最少访问的那条臂。

**场地**：Y 迷宫，**J** 放在交汇点，**A**、**B**、**C** 放在各臂末端。默认臂长 35 cm，臂宽 10 cm。

**设置**：**进臂标准** 0.25 s，动物需在臂内停留这么久才算一次进臂。

| 指标 | 单位 | 定义 |
|---|---|---|
| 自发交替率 | % | 三臂各不相同的连续三元组数 / （进臂次数 − 2）× 100 |
| 进臂次数 | 次 | 全部进臂次数 |
| 交替次数 | 次 | 三臂各不相同的重叠三元组数 |
| 总距离 | m | 步长总和 |
| 追踪成功样本 | % | |

标签：进臂序列，例如 `ABCACBABCBA`。这个例子共 11 次进臂，9 个重叠三元组中有 6 个包含全部三条臂，所以交替率 = 6/9 = 66.7 %。

**如何确定进臂**：每个位置映射到最近的臂中线上，距交汇点 1.1 个臂宽以内算作*中央区*。经过中央区又回到同一条臂，算作再次进入该臂，与人工打分一致，这也会打断交替。手动录入时直接使用输入的序列。

## T 迷宫 {#t-maze}

在左、右两臂之间的自发或奖励性选择。

**场地**：T 迷宫，**J** 交汇点，**S** 起始臂末端，**L**、**R** 两个选择臂末端。默认起始臂 40 cm，选择臂每侧 30 cm，臂宽 10 cm。

**设置**：**进臂标准** 0.25 s。

| 指标 | 单位 | 定义 |
|---|---|---|
| 首选右侧 | % | 第一次进入选择臂为右侧则为 100，左侧为 0，多次试次平均后即为选右的百分比 |
| 左臂进入次数、右臂进入次数 | 次 | 各选择臂的进入次数 |
| 选择臂进入次数 | 次 | 左 + 右 |
| 选择潜伏期 | s | 第一次进入选择臂的时间 |
| 总距离 | m | |

标签：首次选择；进臂序列（`L`/`R`）。重复多次时用 **试次** 区分。

## 新物体识别 {#novel-object-recognition}

比较对新物体与熟悉物体的探索。

**场地**：矩形或圆形，并把标记 **A**、**B** 放在两个物体中心。

**设置**

| 设置 | 默认值 | 含义 |
|---|---|---|
| 新物体 | B | 测试阶段哪个标记是新物体。训练阶段 B 也按“新物体”报告，可用来检查物体或位置偏好。 |
| 交互半径（质心） | 8 cm | 身体中心距物体中心在此距离以内即计为探索 |
| 排除标准（总探索） | 10 s | 总探索时间低于此值的动物会被标记 |
| 进入区域标准 | 0.3 s | 一次接近（探索次数）的最短停留时间 |
| 分析窗口 | 前 300 s | 默认只统计前 5 分钟的探索 |

| 指标 | 单位 | 定义 |
|---|---|---|
| 辨别指数 | — | （新 − 旧）/（新 + 旧），范围 −1 到 1；机会水平为 0 |
| 识别指数 | % | 新 / （新 + 旧）× 100；机会水平为 50 % |
| 新物体探索时间、熟悉物体探索时间 | s | 身体中心位于各物体交互区内的时间 |
| 总探索时间 | s | 新 + 旧 |
| 新物体探索次数、熟悉物体探索次数 | 次 | 满足进入标准的接近次数 |
| 首次接近潜伏期 | s | 第一次接近任一物体的时间 |
| 总距离 | m | |

::: tip 为什么是 8 cm？
经典的探索定义是鼻尖距物体约 2 cm 以内并朝向物体。RodentFlow 追踪的是身体中心，它在鼻尖后方约 4–5 cm。小鼠嗅探直径 4–6 cm 的物体时，身体中心距物体中心约 7–9 cm，所以半径大约取*物体半径 + 5 cm*。仅凭身体中心无法区分嗅探和在物体旁边坐着，请用几段视频和人工打分对照一下。需要按鼻尖打分时，可以改用 **录入数值** 填入人工计时。
:::

组间分析中的组内比较：*新物体 vs 熟悉物体探索*（配对）；组间比较用辨别指数，可选与 0 比较。

## Morris 水迷宫 {#morris-water-maze}

在有隐藏平台的水池中测试空间学习（习得）和记忆（探索测试）。

**场地**：圆形（**C** 圆心，**R** 边缘），填水池直径，再把标记 **P** 放在平台中心。阶段选 **习得** 或 **探索测试**。习得阶段用 **天** 和 **试次** 区分。

**设置**

| 设置 | 默认值 | 含义 |
|---|---|---|
| 平台区半径 | 6 cm | 平台中心周围的半径 |
| 试次最长时间 | 60 s | 计分的试次长度；未找到平台时的潜伏期 |
| 需在平台停留 | 1 s | 在平台区停留满这么久才算逃避成功 |
| 贴壁区宽度 | 10 cm | 沿池壁的环带，用于计算贴壁行为 |
| 试次在视频中的起点 | 0 s | 试次在视频中开始的时间 |

| 指标 | 单位 | 定义 |
|---|---|---|
| 逃避潜伏期 | s | 到达平台区并停留满所需时间的时刻。未找到平台则为试次最长时间，并给出提示。 |
| 路径长度 | m | 到逃避（或试次结束）为止的游泳路径 |
| 游泳速度 | cm/s | 路径长度 / 游泳时间 |
| 找到平台 | % | 找到为 100，否则为 0；多个试次平均后即为找到平台的比例 |
| 目标象限时间 | % | 以平台方向为中心的 90° 扇区内的时间 / 检测到的游泳时间；机会水平为 25 % |
| 对侧象限时间 | % | 相对扇区内的时间 |
| 穿越平台次数 | 次 | 进入平台区的次数（无停留要求） |
| 到达平台区潜伏期 | s | 第一次穿越的时间 |
| 到平台的平均距离 | cm | 游泳过程中到平台中心的平均距离（Gallagher proximity） |
| 贴壁区时间 | % | 在贴壁区内的时间 / 游泳时间 |

**探索测试**没有逃避，所有指标覆盖整个试次窗口，即试次最长时间。请把 **试次最长时间** 设为探索测试的时长，并把 **P** 放在习得阶段平台所在的位置。

学习曲线：在组间分析中选 *跨天比较*，每只动物每天的试次先平均。探索测试：对目标象限 % 做 *组间比较*，可选与 25 % 比较；或用 *配对测量* 比较目标象限与对侧象限。

## Barnes 迷宫 {#barnes-maze}

在明亮的圆形平台上，用唯一的逃生洞测试空间学习。

**场地**：圆形，填平台直径，再把标记 **T** 放在目标（逃生）洞上。其余洞沿同一圆环均匀分布。

**设置**

| 设置 | 默认值 | 含义 |
|---|---|---|
| 洞数 | 20 | 圆环上洞的数量 |
| 洞区半径 | 8 cm | 身体中心距洞中心在此距离以内即计为访问该洞 |
| 试次最长时间 | 180 s | 计分的试次长度 |
| 进入区域标准 | 0.2 s | 一次访问洞的最短停留时间 |
| 试次在视频中的起点 | 0 s | |

| 指标 | 单位 | 定义 |
|---|---|---|
| 初次潜伏期 | s | 第一次访问目标洞的时间 |
| 初次错误数 | 次 | 第一次访问目标洞之前访问其他洞的次数 |
| 总错误数 | 次 | 试次内访问非目标洞的全部次数 |
| 到目标的路径长度 | m | 第一次访问目标洞之前移动的距离 |
| 平均速度 | cm/s | 整个分析试次内的距离 / 时间 |
| 逃避潜伏期 | s | 动物最后一次出现在目标洞附近、之后至少 3 s 看不见（进入逃生箱）的时刻 |
| 目标象限时间、对侧象限时间 | % | 以目标洞为中心的 90° 扇区及其相对扇区内的时间 |
| 到目标的平均距离 | cm | 到目标洞的平均距离 |

标签：以相对目标洞的偏移表示的访问洞序列（`-3 -2 -1 T`），以及**搜索策略**：

- *直接*：第一次就到目标洞，或之前最多查看两次相邻的洞；
- *顺序*：沿同一方向依次访问至少三个相邻的洞；
- *随机*：其他情况。

::: tip 身体中心，而不是鼻尖
访问洞是用身体中心近似的探鼻。深色小鼠探洞时头会消失在洞里，可见身体的中心距洞中心约 5–7 cm，所以默认洞区设为 8 cm。每次访问只归到最近的洞，相邻洞区重叠也不会重复计数。
:::

## 恐惧条件化 {#fear-conditioning}

僵直指除呼吸外完全不动，根据前后帧的像素变化测量。

**场地**：矩形，放在箱子底面上。阶段选 **训练**、**情境测试** 或 **线索测试**。

**设置**

| 设置 | 默认值 | 含义 |
|---|---|---|
| 僵直阈值 | 5 %（变化像素占身体面积） | 运动低于此值计为静止（见下文） |
| 最短僵直时长 | 1.0 s | 短于此值的静止不算僵直 |
| 实验程序在视频中的起点 | 0 s | 实验程序计时在视频中开始的时间 |
| 基线（CS 前） | 120 s | 从实验程序开始算起的基线时长（最晚到第一次 CS 开始为止） |
| CS 时长 | 30 s | 每次 CS 的长度 |
| CS 起始时间 | — | 自实验程序开始的秒数，如 `120, 210, 300`。**等间隔填充** 可以根据次数、第一次起始时间和间隔自动生成。 |
| 分析长度 | 0 = 全部 | 从实验程序开始算起的分析时长 |
| 时间段 | 1 min | 分段僵直的时长（30 s、1 min、2 min） |

| 指标 | 单位 | 定义 |
|---|---|---|
| 僵直（全程） | % | 僵直时间 / 分析时间 × 100 |
| 基线僵直 | % | 基线期间的僵直 |
| CS 期僵直 | % | 所有 CS 期间僵直的平均值 |
| CS 后 / 试次间隔僵直 | % | 第一次 CS 开始之后、CS 时段以外的僵直 |
| 僵直次数 | 次 | 僵直片段数 |
| 平均僵直时长 | s | 僵直片段的平均长度 |

序列：每次 CS 的僵直、每个时间段的僵直。结果页显示运动曲线以及僵直片段、基线和 CS 时段。

**“变化像素占身体面积 %”是什么**：对每一对相隔 0.1 s 的相邻帧，App 统计场地内亮度变化至少 20 个灰度级的像素数，再除以动物的典型身体面积，即整个实验中追踪到的身体大小的中位数。这样，阈值对大动物、小动物，以及近处、远处的相机都有相同的含义。在上图中，运动的小鼠为 20–90 %，静止的小鼠低于 3 %。见[僵直](../principles/metrics.md#freezing)。

::: warning 每套装置校准一次阈值
光照、相机和垫料都会影响运动信号。用自己装置拍的 3–5 段视频人工打分，在 App 里试几个阈值（结果会立即更新）对照，选一致性最好的阈值，用于之后的所有动物。
:::
