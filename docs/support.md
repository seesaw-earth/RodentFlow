## Report a problem or ask a question {#help}

Open an issue on GitHub: **[github.com/seesaw-earth/RodentFlow/issues](https://github.com/seesaw-earth/RodentFlow/issues)**

Earlier reports about the Mac app are in the [RodentStudio-Support issue tracker](https://github.com/seesaw-earth/RodentStudio-Support/issues); check there whether a problem is already known.

To help us help you, please include:

1. **App and version.** iPhone or iPad: Settings › General › iPhone Storage › RodentFlow. Mac: **RodentFlow › About RodentFlow**, or TestFlight.
2. **Device and system.** iPhone or iPad model and iOS version; or macOS version and whether the Mac has Apple silicon or Intel.
3. **Workflow and assay.** Centroid tracking, RodentPose, RodentLimb or multi-chamber tail suspension; video, manual entry or import.
4. **What you did, what you expected, and what happened**, with the exact error message.
5. If it concerns tracking: a **screenshot of the preview** and, if you can share it, a short clip or a synthetic test clip.
6. If it concerns an import: the **first lines of the file**, with real animal IDs replaced if needed.

::: warning Mind what you share
GitHub issues are public. Do not post unpublished data, identifiable information, or videos you are not allowed to share. A screenshot or a few anonymized rows are usually enough.
:::

## Privacy or sensitive requests

If your question involves personal, confidential or unpublished information, open an issue containing only a request for a private contact channel; do not include the sensitive details. The developer can then arrange a private follow-up.

## What support covers

Installation and app behaviour, access to the video files you choose, Core ML model loading, import and export questions, and reproducible defects. RodentFlow does not provide clinical, veterinary or experimental protocol advice.

## Source code

The source code is public; see [Source code](./source.md). Pull requests are welcome; see [CONTRIBUTING.md](https://github.com/seesaw-earth/RodentFlow/blob/main/CONTRIBUTING.md).

## Feature requests

New assays, metrics or export formats are welcome as GitHub issues. Please describe the protocol, the measure you need, and how it is defined in your field. A reference to a methods paper helps.

Found a mistake in this manual? Every page has an *Edit this page on GitHub* link, or [open an issue](https://github.com/seesaw-earth/RodentFlow/issues/new/choose).
