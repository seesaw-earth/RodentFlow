# Pose, limb and Mac assay reference

The table lists what each assay needs at calibration and what it reports first. Every threshold and zone is adjustable in *Calibrate*; exported measure keys are shown in `code`.

## RodentPose (Mac, iPhone, iPad) — 6 keypoints {#assays-pose}

| Assay                             | Arena & markers                       | Phases                                       | Primary measure                                       | Notes                                                                                                                              |
|-----------------------------------|---------------------------------------|----------------------------------------------|-------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------|
| Three-Chamber Sociability         | Rectangle 1–4; dividers L/R; cups L/R | Sociability, Social novelty, Habituation     | Sniffing index `sniff_index`                          | Set which cup holds the stranger; cup radius, investigation distance, head-direction tolerance                                     |
| Social Interaction Test           | Rectangle 1–4; enclosure wall         | Target absent, Target present                | Interaction-zone time `iz_time`; SI ratio when paired | Analyse both phases under the same subject ID to pair automatically ([Golden 2011](https://doi.org/10.1038/nprot.2011.361): 150 s) |
| Dyadic Social Interaction         | Rectangle or circle                   | —                                            | Total social contact `social_total`                   | Two-mouse mode on iPhone/iPad; identities can swap after overlap. Mac: single-animal tracking only                                 |
| Head Direction                    | Rectangle or circle; cue Q (optional) | —                                            | Direction coverage `hd_coverage`                      | Align recording-system timestamps yourself; CSVs include frame times                                                               |
| Spatial Exploration · Place Cells | Rectangle or circle                   | —                                            | Coverage `coverage`                                   | For long recordings, every 2nd–3rd frame saves time (mobile)                                                                       |
| Open Field                        | Rectangle or circle                   | —                                            | Centre time % `center_pct`                            | Centre zone default 50 % of side                                                                                                   |
| Elevated Plus Maze                | Plus maze C/N/E/S/W                   | —                                            | Open-arm time % `open_time_pct`                       | Choose the open-arm axis; head dips and stretch-attend posture detected                                                            |
| Light–Dark Box                    | Rectangle 1–4                         | —                                            | Light-box time % `light_pct`                          | Set light-side location and fraction                                                                                               |
| Novel Object Recognition          | Rectangle or circle; objects A/B      | Test, Training                               | Discrimination index `di`                             | Nose-based investigation; set which object is novel in Test                                                                        |
| Barnes Maze                       | Circle C/R; target T                  | Learning, Probe trial                        | Primary latency `primary_latency`                     | Hole count, hole radius, probe margin                                                                                              |
| Y-Maze Spontaneous Alternation    | Y-maze J/A/B/C                        | —                                            | Alternation % `alternation_pct`                       | Arm-entry criterion: body centre + tail base, body centre, or nose                                                                 |
| T-Maze · VTE                      | T-maze J/S/L/R                        | —                                            | VTE % `vte_pct`                                       | Analyse every frame; zIdPhi threshold adjustable                                                                                   |
| Fear Conditioning                 | Rectangle 1–4                         | Cued test, Context test, Training            | CS freezing `freeze_cs_mean`                          | Enter CS onset times (s from video start) or generate evenly spaced events; IR/grayscale works best                                |
| Looming-Evoked Escape             | Rectangle or circle; shelter S        | —                                            | Escape probability `escape_pct`                       | Enter each stimulus onset time                                                                                                     |
| Rotational Behavior               | Circle, rectangle or none             | Apomorphine, Amphetamine, Spontaneous, Other | Net rotations/min `net_per_min`                       | Set the lesion side; “Recorded from below” mirrors direction; 5-min bins                                                           |
| Pose Data Only                    | None, rectangle or circle             | Free text                                    | Detection rate `detection_rate`                       | Pixels without calibration; centimetres with it                                                                                    |

## RodentFlow (Mac) — centroid at 10 Hz {#assays-flow}

| Assay                        | Arena & markers            | Phases                              | Primary measure                                          | Notes                                                                                             |
|------------------------------|----------------------------|-------------------------------------|----------------------------------------------------------|---------------------------------------------------------------------------------------------------|
| Open Field / Center          | Rectangle or circle        | —                                   | Total distance `distance_m`                              | Centre zone size, moving threshold, minimum immobility bout, time bins                            |
| Elevated Plus Maze           | Plus maze C/N/E/S/W        | —                                   | Open-arm time % `open_time_pct`                          | Open-arm pair, extra centre margin                                                                |
| Light–Dark Box               | Rectangle                  | —                                   | Light-box time % `light_time_pct`                        | Option: count unseen samples as dark (covered dark box)                                           |
| Y-Maze                       | Y-maze J/A/B/C             | —                                   | Spontaneous alternation % `alternation_pct`              | Entries need 0.25 s stable occupancy                                                              |
| T-Maze                       | T-maze J/S/L/R             | — (trials)                          | Right first choice % `right_choice_pct`                  | Choice latency, arm entries                                                                       |
| Novel Object Recognition     | Rectangle or circle; A/B   | Training, Test                      | Discrimination index `discrimination_index`              | Interaction radius from body centre ≈ object radius + 5 cm; total-exploration exclusion criterion |
| Morris Water Maze            | Circle C/R; platform P     | Acquisition, Probe (days, trials)   | Escape latency (acquisition) / target quadrant % (probe) | Platform zone, trial maximum, stay criterion, wall zone                                           |
| Barnes Maze                  | Circle C/R; target T       | Acquisition, Probe (days, trials)   | Primary latency / target quadrant %                      | Errors = body-centroid proxy for nose pokes                                                       |
| Fear Conditioning            | Rectangle                  | Training, Context test, Cue test    | Freezing % / CS freezing %                               | Motion-index threshold; protocol start, baseline, CS onsets — check against hand-scored clips     |
| Conditioned Place Preference | Rectangle; 2 or 3 chambers | Pre-test, Conditioning, Test (days) | Preference score (paired − unpaired, s)                  | Divider position, paired side; CPP score = test − pre-test via *Change between phases*            |

## RodentLimb (Mac) — 7 keypoints {#assays-limb}

| Assay                          | Calibration                                          | Reports                                                                          | Key parameters                                                                                                                                                                              |
|--------------------------------|------------------------------------------------------|----------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Cylinder test                  | Cylinder rim (bottom view) or floor line (side view) | Forelimb wall contacts during rearing: left, right, both, use asymmetry          | Lesioned hemisphere, swap L/R labels for mirrored views, wall zone, minimum contact, score first n min / first n contacts ([Schallert 2000](https://doi.org/10.1016/S0028-3908(00)00005-8)) |
| Tail suspension (single mouse) | Ruler (optional)                                     | Immobility, latency, per-minute profile, hind-limb clasping, tail climbing       | Window 120–360 s by default, motion threshold, minimum bout, clasping window (~10 s, [Guyenet 2010](https://doi.org/10.3791/1787))                                                          |
| Gait                           | Ruler (known distance)                               | Stance/swing, stride, duty factor, base of support, inter-limb phase, regularity | Minimum walking speed, maximum turning rate (±20 °/s), drop first/last stride, speed-matched reference speed — same values for every animal                                                 |
