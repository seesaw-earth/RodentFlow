# Keyboard shortcuts (Mac)

| Shortcut                                                                       | Action                            | Where                         |
|--------------------------------------------------------------------------------|-----------------------------------|-------------------------------|
| <kbd>⇧</kbd><kbd>⌘</kbd><kbd>N</kbd>                                           | New task…                         | Anywhere                      |
| <kbd>⌘</kbd><kbd>O</kbd>                                                       | Add videos… / Add TST recording…  | With a task selected          |
| <kbd>⌘</kbd><kbd>1</kbd> · <kbd>⌘</kbd><kbd>2</kbd> · <kbd>⌘</kbd><kbd>3</kbd> | Tasks · All sessions · Tools      | Anywhere                      |
| <kbd>⌘</kbd><kbd>+</kbd> / <kbd>⌘</kbd><kbd>−</kbd>                            | Increase / decrease text size     | Anywhere                      |
| <kbd>⌘</kbd><kbd>,</kbd>                                                       | Settings (language, text size)    | Anywhere                      |
| <kbd>⌘</kbd><kbd>[</kbd> / <kbd>⌘</kbd><kbd>]</kbd>                            | Previous / next step              | Session                       |
| <kbd>⌘</kbd><kbd>S</kbd>                                                       | Save calibration for this video   | Calibrate                     |
| Arrow keys (<kbd>⇧</kbd> = larger)                                             | Nudge the selected handle         | Calibrate                     |
| <kbd>⌘</kbd><kbd>R</kbd>                                                       | Analyse this video / Resume       | Analyse                       |
| <kbd>⌥</kbd><kbd>P</kbd>                                                       | Play / pause                      | Frame review                  |
| <kbd>⌥</kbd><kbd>←</kbd> / <kbd>⌥</kbd><kbd>→</kbd>                            | Previous / next frame (or sample) | Frame review                  |
| <kbd>⌥</kbd><kbd>F</kbd>                                                       | Flag “Wrong tracking here”        | Frame review                  |
| <kbd>⌘</kbd><kbd>E</kbd>                                                       | Export selected files and figures | Frame review & export         |
| <kbd>Return</kbd> / <kbd>Esc</kbd>                                             | Next step / cancel                | TST recording window, dialogs |
