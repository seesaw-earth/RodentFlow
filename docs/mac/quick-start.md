# Quick start on Mac (10 steps)

1.  **Open RodentFlow.** To switch between English and 中文, use the globe *Language* menu in the toolbar or **RodentFlow › Settings…** (<kbd>⌘</kbd><kbd>,</kbd>).
2.  **Create a task:** click **New task…** (<kbd>⇧</kbd><kbd>⌘</kbd><kbd>N</kbd>), answer “What are you measuring?”, and pick the test (search helps). A project is created automatically.
3.  **Add videos:** click **+ Add videos…** (<kbd>⌘</kbd><kbd>O</kbd>) or drag files onto the sidebar / list.
4.  **Check the import form:** animal ID, date and session number are required; group and sex are optional. Use *Group for new animals → Apply* to fill a column. Click **Import**.
5.  **Open a session** in the middle list. Work through the four steps at the top: **① Session info → ② Calibrate → ③ Analyse → ④ Review & export** (<kbd>⌘</kbd><kbd>[</kbd> / <kbd>⌘</kbd><kbd>]</kbd> move between steps).
6.  **Calibrate:** drag the coloured handles onto the arena (a magnifier appears while you drag), enter the real arena size in cm, set the analysis window, then **Save for this video** (<kbd>⌘</kbd><kbd>S</kbd>). If the camera did not move, choose **Use for all videos of this task…**
7.  **Analyse:** click **Analyse this video** (<kbd>⌘</kbd><kbd>R</kbd>). Further videos join a queue; you can keep calibrating or reviewing while it runs, and **Pause** / **Resume** at any time.
8.  **Check tracking:** in *Review & export → Frame review & export*, play frames 0–99 (<kbd>⌥</kbd><kbd>P</kbd>), flag mistakes (<kbd>⌥</kbd><kbd>F</kbd>), and record *Tracking OK* or *Tracking problems*. Then **Next session to check →**.
9.  **Look at the numbers:** the *Results* tab shows the assay’s measures and figures. Click the task in the sidebar for all sessions and **Compare groups**.
10. **Export:** on the task page, **Export task data…** creates a folder of English CSV files plus `README_methods.txt`, ready for R, Python, Prism or Excel.

::: tip

**Tip:** calibrate and check the first animal of a batch carefully. New videos of the same task start from the previous calibration (you will see “Calibration reused from … — check it”), so later animals usually need only a quick glance.

:::
