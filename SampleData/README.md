# Example data (synthetic)

These CSV files are **synthetic demo data generated by a script**, not results from real animals.
Use them to try the import sheet and the Groups tab (AirDrop / Files → Import Table, then choose the assay):

| File | Assay to choose | What it demonstrates |
|---|---|---|
| example_open_field_metrics.csv | Open Field / Center | Per-animal table with free-form headers ("Total distance (m)", "Center time (%)"); 3 groups → ANOVA + Tukey |
| example_open_field_chinese_headers.csv | Open Field / Center (旷场 / 中央区) | Same data with Chinese headers (编号, 组别, 性别, 总距离 (m), …). Metric headers in Chinese are recognized when the app runs in Chinese; 编号 / 组别 / 性别 work in either language. |
| example_sucrose_raw.csv | Sucrose Preference | Raw bottle weights per day → preference computed in the app |
| example_beam_trials.csv | Beam Walking | Trials within days → "Across days" learning curve, mixed ANOVA |
| example_mwm_acquisition.csv | Morris Water Maze | 4 trials × 5 days → trials averaged per animal-day |
| example_nor_test.csv | Novel Object Recognition | Hand-scored times → DI, paired novel vs familiar; one animal is flagged for low exploration |
| example_bandit_trials.csv | Two-Armed Bandit | 300 trials per mouse with reversals → win-stay / lose-shift, Q-learning fit |
